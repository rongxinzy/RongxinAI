Everything an AI Agent Needs

LEO is not just a chat UI. It's an execution environment where Agents work on your machine, access tools, run code, and stay reachable through your everyday channels.

Cowork Agent Workflows

Multi-step tasks with file tools, shell commands, browser automation, document processing, and approval-gated actions. Real-time streaming of messages, tool calls, and permission requests.

OpenClaw Runtime Stream Events Permission Control

llama.cpp Local Inference

Manage local GGUF models with a full lifecycle: install, list, load, configure launch parameters (context length, GPU offload, threads), and run llama-server locally. Model marketplace backed by ModelScope with 40K+ models.

Privacy First

Your Data Stays Local

Every session, config, skill, task, and memory lives in local SQLite. No telemetry, no cloud dependency — unless you choose to connect to an API.

🔒

Process Isolation

Context isolation enabled, node integration disabled, sandbox enabled. The renderer communicates exclusively through typed IPC channels — no direct filesystem or network access.

🛡️

Approval-Gated Actions

Risky tool calls — shell execution, file modifications, browser automation — require explicit user approval. A permission modal lets you review each action before it runs.

🧹

Sandboxed Artifacts

HTML rendered in sandboxed iframes with no allow-same-origin. SVG sanitized by DOMPurify. React components isolated in iframes with no network access. Mermaid with strict security level.
