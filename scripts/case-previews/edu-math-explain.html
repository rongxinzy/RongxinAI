A · 决定最值的六件事 动手前先定位：这一条公式管什么
概念公式作用例（f(x) = x² − 2x + 3）
二次函数一般式f(x) = ax² + bx + c（a ≠ 0）统一形式，先看 a 的符号定开口方向a = 1，b = −2，c = 3

Chapter 02 · 核心概念与例子

配方全过程与 5 类区间情形的最值

主线函数：f(x) = x² − 2x + 3
顶点 (1, 2) · 轴 x = 1 · 开口向上
f(x) = x² − 2x + 3配方 → (x − 1)² + 2轴 x = 1顶点 (1, 2) · 判别式 Δ = −8 < 0

配方过程：x² − 2x + 3 = (x² − 2x + 1) + 3 − 1 = (x − 1)² + 2，即「加一次项系数一半的平方（1），再减回去」。由此读三个结论：a = 1 > 0 开口向上；对称轴 x = −b/2a = 2 / 2 = 1；顶点 (1, 2) 是最小值点，最小值 2。

① 配方 → (x − 1)² + 2→② 读对称轴 x = 1→③ 判轴与区间位置→④ 比较端点与顶点
配方结果

x² − 2x + 3 = (x − 1)² + 2，顶点 (1, 2)：括号内取 0 时最小，故最小值 2；a < 0 时顶点给最大值。

记忆锚点

「先看轴在不在区间内」：轴在区间内，顶点值是候选；轴在区间外，区间上单调，最值只在两端点。

三类区间情形（5 类的合并）

轴在区间左 → 单调递增；轴在区间内 → 顶点给一侧最值；轴在区间右 → 单调递减；再按中点细分共 5 类。

5 类区间情形（4 类相对位置 + 中点特例）× 最值取法 第 5 类见下方引注
情形位置条件（轴 = −b/2a）最值取值式数值验证（对应区间）
① 左外侧轴 ≤ m最小值f(m)[2, 4]：f(2) = 4 − 4 + 3 = 3
① 左外侧轴 ≤ m最大值f(n)[2, 4]：f(4) = 16 − 8 + 3 = 11
② 左半区m < 轴 < (m+n)/2最小值f(轴)[0, 3]：f(1) = 2
② 左半区m < 轴 < (m+n)/2最大值f(n)[0, 3]：f(3) = 6
③ 右半区(m+n)/2 < 轴 < n最小值f(轴)[−1, 2]：f(1) = 2
③ 右半区(m+n)/2 < 轴 < n最大值f(m)[−1, 2]：f(−1) = 6
④ 右外侧轴 ≥ n最小值f(n)[−3, −1]：f(−1) = 6
④ 右外侧轴 ≥ n最大值f(m)[−3, −1]：f(−3) = 9 + 6 + 3 = 18
第 5 类「轴 = 中点」（②③ 的临界）：区间 [−1, 3] 的中点 1 = 轴，f(−1) = f(3) = 6，最小值 2（x = 1），最大值 6。
一句话结论：闭区间最值只有三个候选：f(m)、f(n) 与顶点值（轴在区间内时才参选）。第 4 / 10 页

6 类高频错误与 4 行最值对照

A · 6 类常见错误 先看「典型错误」一列，能自己改对再往下
类型典型错误正确写法原因与记忆点
忽略 a 正负写「最大值是 2」a = 1 > 0，顶点值 2 是最小值顶点给最大还是最小由 a 的符号决定。
轴外仍套顶点[2, 4] 上写 min = 2轴 1 ∉ [2, 4]，min = 3顶点值只在轴落进区间时才可达。
只比顶点只写最小值 2，不写最大值再算 f(0) = 3、f(3) = 6，最大 6轴把区间分成两段相反单调，端点都要算。
忽略开闭区间把 (0, 3) 当成 [0, 3]开区间无最大值，min = 2 仍取到端点取不到时最值可能不存在，只能写上确界 6。
对称轴符号写反x = b / 2a = −1x = −b / 2a = 2 / 2 = 1b = −2
漏写取等条件只写「最小值为 2」当且仅当 x = 1 时取最小值 2最值必须给出取等条件，否则解答不完整。
B · 三种区间情形的正确最值 对照表，数值与 P4 完全一致
轴与区间位置最小值最大值数值（f(x) = x² − 2x + 3）
轴在左（[2, 4]）f(m) = f(2) = 3f(n) = f(4) = 11区间递增：min 3（x = 2）· max 11（x = 4）
轴在内（[0, 3]）f(轴) = f(1) = 2f(n) = f(3) = 6轴偏左半区：max 6（x = 3），f(0) = 3 不是最大
轴在内（[−1, 2]）f(轴) = f(1) = 2f(m) = f(−1) = 6轴偏右半区：最大值取左端点，min 2（x = 1）
轴在右（[−3, −1]）f(n) = f(−1) = 6f(m) = f(−3) = 18区间递减：min 6（x = −1）· max 18（x = −3）
动笔前 3 秒自检

一看 a 的符号；二算 x = −b/2a（b 本身带负号）；三比轴与区间端点的大小。这三条对上，开口与轴相关的错误基本清零。

开区间与闭区间的差别

[0, 3]：最小 2、最大 6 都存在；(0, 3)：最小 2 仍取到（x = 1），最大不存在，上确界为 6。

纠错结论：最值失分只有两个源头：开口没判、轴没和区间比大小。第 5 / 10 页

术语释义
顶点抛物线的最高点或最低点；x² − 2x + 3 的顶点为 (1, 2)。
对称轴抛物线左右对称的竖直线，方程 x = −b/2a；本讲主线函数为 x = 1。
判别式Δ = b² − 4ac，判断与 x 轴交点个数；x² − 2x + 3 的 Δ = −8 < 0，无交点。
单调区间函数保持递增或递减的区间；a > 0 时轴左递减、轴右递增。
闭区间形如 [m, n] 的区间，两端点都能取到；(m, n) 为开区间，端点取不到。
最值区间上取得的最大值或最小值，须给出取等条件，如「x = 1 时取最小值 2」。
参变量除自变量外出现在系数里的字母，如 x² − 2ax + 3 中的 a，需分类讨论。
恒成立不等式对区间内每个 x 都成立；f(x) ≥ m 在 [0, 3] 上等价于 m ≤ 最小值 2。
值域函数取值的集合；x² − 2x + 3 在 [0, 3] 上的值域为 [2, 6]，全局为 [2, +∞)。
分类讨论按轴与闭区间的相对位置（5 类）分别求最值，并写出取到时的 x 值。
