为什么先算 Δ 就能拦住一半

写 Δ 必须用到 a、b、c 三项，等于强制核对系数；本题 Δ = 49，而误按 a = 1 算得 Δ = 29，一算就会暴露。

Chapter 02 · 核心概念与例子

原题还原：8 行对照看清错在哪一步

原题 2x² + 3x − 5 = 0
正确结果 Δ = 49，根为 1 与 −2.5
2x² + 3x − 5 = 0a = 2 · b = 3 · c = −5Δ = 49

还原一次：卷面把 a 记作 1，代入却按 a = 2 运算，两根仍是 1 与 −2.5；若真按 a = 1 算，Δ = 29，根 ≈ 1.19 与 −4.19，结果对错掩盖了过程错误。

还原过程→定位错因→归类→迁移到变式
第一步 标准形式与系数

写成 2x² + 3x − 5 = 0，把 a = 2、b = 3、c = −5 单列一行，不凭「2x²」的印象取数。

第二步 判别式 Δ = 49

Δ = 3² − 4×2×(−5) = 9 + 40 = 49 > 0，两个不等实根；Δ 只判根的情况，本身不是根。

第三步 回代验算

x = 1 时 2 + 3 − 5 = 0；x = −2.5 时 12.5 − 7.5 − 5 = 0，两边都等于 0 才算解完。

8 行对照 「是否影响最终结果」一列最容易漏，务必逐行看完
错因当时的做法正确做法是否影响最终结果
漏二次项系数卷面写 a = 1，代入时 Δ 用 4×2×(−5)、分母用 2×2a = 2、b = 3、c = −5 逐项抄写后再代入本题不影响：算出的根仍是 1 与 −2.5，与正确答案相同
判别式未计算直接写 x = (−3 ± 7) / 4，跳过 Δ 这一步先写 Δ = 9 + 40 = 49 > 0不影响本题结果，但问「有几个根」的题必错
分母写错写成 x = (−3 ± 7) / 2，把 2a 当成 2分母是 2a = 2×2 = 4影响：根变成 2 与 −5，与 1、−2.5 完全不同
符号写错把 c 写成 5，Δ 得 9 − 40 = −31c = −5 连符号代入，Δ = 9 + 40 = 49影响：Δ 由 49 变 −31，会被误判为无实根
未化标准形式x(2x + 3) = 5 未移项，常数项当成 0展开移项成 2x² + 3x − 5 = 0 再取系数影响：Δ 由 49 变 9，根变成 0 与 −1.5，两根全错
跳步省略中间式一行写出 4 / 4 与 −10 / 4 的结果，不写来源写 x₁ = 4 / 4 = 1、x₂ = −10 / 4 = −2.5不影响本题，但检查时无法定位错在哪一步
把 Δ 当根算出 49 后直接写「根为 49」√49 = 7，再代入 x = (−3 ± 7) / 4影响：答案完全错，根是 1 与 −2.5，不是 49
不回代验算得到 1 与 −2.5 就交卷2×1² + 3×1 − 5 = 0 与 2×(−2.5)² + 3×(−2.5) − 5 = 0不影响本题，但它是唯一能拦住以上所有错误的动作
一句话结论：先列 a、b、c 再写 Δ，这两步能挡住 8 行里的前 5 类错误。第 4 / 10 页

交卷前 3 秒自检

一看 a 是否就是二次项系数（本题 2）；二看 Δ 是否算过并写了符号；三看两个根是否都化简并回代。三条对上，6 类错因清零。

这道题为什么特别容易错

2x² 的系数 2 与分母 2a 的 2 容易混，且 Δ = 49 是完全平方、根又是有理数，结果「好看」会让人以为过程无误。

纠错结论：漏系数、未写判别式、符号错、把 Δ 当根这 4 类，靠「先列系数、再写 Δ」就能拦住。第 5 / 10 页

基础题 6 道 只考系数、判别式与公式代入
  • 1. 把 2x² + 3x − 5 = 0 写成标准形式，并单独列出 a、b、c 的值（三项都要带符号）。
  • 2. 计算原题的判别式 Δ，写出计算式与 Δ 的符号，并说明它对应几个实根。
  • 3. 用求根公式求原题的两个根，要求写全「代入 Δ 与 2a」「拆成两个根」「化简」三步。
  • 4. 不解方程，判断 x² − 2x + 3 = 0 的根的情况，并写出依据（要给出 Δ 的值）。
  • 5. 回代验算：把 x = 1 与 x = −2.5 分别代回 2x² + 3x − 5 = 0，写出等式两边的具体数值。
  • 6. 判断错因：某同学卷面写 a = 1，代入时 Δ 用了 4×2×(−5)、分母用了 2×2，结果得 1 与 −2.5。指出这属于 6 类错因中的哪两类。
进阶题 4 道 进入变式、根的讨论与评语写作
  • 7. 完整求解 3x² − 7x + 2 = 0：先列 a、b、c，再算 Δ，再用公式写根，最后回代其中一个根。
  • 8. 判断 x² − 4x + 4 = 0 的根的情况并求出根，再说明 Δ = 0 与 Δ > 0 在图象上的区别。
  • 9. 关于 x 的方程 kx² + 2x + 1 = 0 有实根，求 k 的取值范围（分 k = 0 与 k ≠ 0 两种情形讨论）。
  • 10. 给下面这道学生解法写 60 字以内评语：2x² + 3x − 5 = 0，a = 1，b = 3，c = −5，Δ = 9 + 20 = 29，x = (−3 ± 7) / (2 × 2)，x₁ = 1，x₂ = −2.5。评语要指出错处并写出正确过程的关键一步。
挑战题 2 道 需要成页或成条输出，按栏位与覆盖度评分

10评语：a 应为 2（漏了二次项系数），且 Δ 写 29 却代入 √49 = 7，前后不一致。正确关键一步：Δ = 9 + 40 = 49，x = (−3 ± 7) / 4，x₁ = 1、x₂ = −2.5两处错误各占一半；只说「算错了」不给分。
11五栏：原题 / 错误过程 / 错因归类 / 正确过程 / 防错口令。样例：错误过程记 a = 1、Δ 写 29 却代 7；归类为漏系数 32% + 跳步 24%；正确过程 Δ = 49、根 1 与 −2.5五栏缺一扣分；错因必须写到类别名，只写「粗心」不得分。
12三步清单：① 动笔前并排列出标准形式与 a、b、c（拦漏系数 32%、符号错 12%、未写标准形式 10%）② 先写 Δ 并标符号再写根（拦跳步 24%）③ 交卷前回代两个根（拦靠结果判断 16%、不验算 6%）每步都要标出对应类别；三句合计超过 60 字扣分。

术语释义
标准形式一元二次方程写成 ax² + bx + c = 0（a ≠ 0）；2x² + 3x − 5 = 0 已是标准形式。
二次项系数标准形式中 x² 前的系数 a，本题 a = 2；漏取或误取成 1 会让 Δ 与根一起错。
判别式Δ = b² − 4ac，本题 Δ = 3² − 4×2×(−5) = 49；Δ > 0 时两个不等实根。
求根公式x = (−b ± √Δ) / (2a)；Δ = 49 时 x = (−3 ± 7) / 4，得 1 与 −2.5。
韦达定理两根之和 x₁ + x₂ = −b / a = −1.5，两根之积 x₁x₂ = c / a = −2.5。
因式分解把 2x² + 3x − 5 写成 (2x + 5)(x − 1)，两根由 2x + 5 = 0 与 x − 1 = 0 得到。
回代验算把根代回原方程看两边是否相等；x = 1 时左边 2 + 3 − 5 = 0，两边成立。
错因归类把一次错误归入 6 类错因并记录占比，本题属「公式代入漏系数」类，占 32%。
变式迁移换系数、换问法重做同一结构，如把原题换成 3x² − 7x + 2 = 0（Δ = 25）。
根的分布由 Δ 的符号与二次函数图象判断根的个数与范围，含参题靠它讨论 k 的取值。
