# 移除外部 IM 频道能力说明

> 日期：2026-05-13
> 分支：fix/deleteNIMapp
> 范围：外部 IM 频道插件、主进程网关、IPC、前端设置入口、类型定义、持久化读写、测试与文档

## 背景

项目此前保留过一个外部企业 IM 频道实现。它包含独立 SDK 网关、扫码辅助登录、频道插件配置同步、前端实例配置页、状态展示、连通性探测、调度任务通知目标和若干兼容迁移逻辑。

本次需求是完整拆除该频道能力，而不是仅删除运行时插件。拆除后应用不再展示、保存、启动、同步或测试该频道，也不再把该频道作为调度任务、智能体绑定或前端 IM 设置中的可选项。

## 拆除目标

1. 移除外部频道插件依赖和安装入口，避免构建或运行时准备流程继续下载、缓存或复制相关插件。
2. 删除主进程 SDK 网关、媒体处理、扫码登录服务和对应 IPC 注册。
3. 删除配置存储中的频道读写、实例迁移、启停、状态、连通性探测和通知分发分支。
4. 删除 OpenClaw 配置同步中的频道配置、密钥环境变量和智能体绑定生成逻辑，同时保留对历史插件入口的清理能力。
5. 删除前端 IM 设置页入口、实例配置组件、扫码登录服务、Redux 状态分支和 Electron 类型声明。
6. 更新测试、README、开发说明和本变更说明，使公开文档不再描述已移除频道。

## 后端变更

- 删除专用网关、媒体工具、扫码登录服务和频道客户端文件。
- 删除主进程中的扫码登录 IPC 注册，以及实例新增、删除、配置保存相关 IPC 处理器。
- 删除网关管理器中的该频道实例、启停、状态汇总、连通性探测、缺失凭证判断和通知发送分支。
- 删除 IM 配置存储中的该频道默认配置、实例迁移、单实例兼容读取、多实例持久化和删除逻辑。
- 删除调度任务频道枚举和频道会话同步中的该频道多实例特殊处理。
- 删除企业配置导入中的该频道配置映射。

## 前端变更

- 删除 IM 设置侧边栏中的该频道入口。
- 删除实例配置面板、扫码登录表单、动态 schema 回退配置和相关服务。
- 删除 Redux 配置和状态中的该频道字段。
- 删除 Electron preload 暴露的扫码登录与实例管理 API。
- 删除渲染进程类型声明中的该频道配置、状态、扫码登录和连通性枚举。
- 删除调度任务表单中的该频道会话 ID 特殊匹配逻辑。

## 配置同步行为

完整拆除后，运行时同步不再生成以下内容：

- 频道配置节点。
- 频道凭证环境变量。
- 频道级或实例级智能体绑定。
- 频道相关调度通知目标。

为了兼容已安装用户的旧本地配置，同步逻辑仍会在生成配置时清理历史插件入口，避免运行时继续尝试加载已移除插件。

## 数据兼容说明

本次变更不主动删除用户本地 SQLite 中可能残留的历史键值，只是不再读取、展示或写回这些键值。这样可以避免升级时对本地数据库执行破坏性清理，同时确保新版本运行路径不会再依赖该频道。

## 风险与处理

### 历史配置残留

旧数据库里可能仍有历史频道配置。应用启动后这些配置不会进入 UI、网关管理器或运行时配置同步；旧运行时插件入口会在配置生成阶段被清理。

### 自定义运行时仍包含旧插件

如果某个本地运行时目录手动放入旧插件，新版本也不会再为它生成频道配置或凭证环境变量。该插件不再属于应用支持范围。

### 前端缓存或旧构建产物

如果用户看到旧设置项，应确认使用的是本分支重新构建后的前端产物，并清理旧构建缓存。源码层面已删除入口、组件和类型引用。

## 验证范围

本次变更应重点验证：

- Electron 主进程 TypeScript 编译通过。
- IM 设置页仍可正常展示保留频道。
- 调度任务通知渠道仍能列出保留频道。
- OpenClaw 配置同步不会生成已移除频道配置。
- 历史插件入口会从运行时配置中清理。
- README 与开发说明不再公开描述已移除频道。
