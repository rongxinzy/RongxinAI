# 伙伴对话窗：阶段验收

## 本次范围

独立、可聚焦的伙伴对话窗；七个独立身份；原生持久聊天；自动分配已同意开启的模型；草稿保留；隐藏与停止分开。入口是伙伴菜单、托盘及 `CommandOrControl+Shift+Space`。模型选择仍在原有设置中，不新增伙伴专属模型下拉框。工作台能力保留。

此阶段只交付聊天入口。任务交代、附件、工作区选择、权限确认、同一 Task/Run 展开工作台、私有记忆、主动跟进、连续媒体与 Windows 攀爬仍按完整清单推进，不能把「打开工作台」算作任务贯通。

主进程翻译表原为 60 KB，先机械拆成六个数据模块，抽取时逐键比较原中英词条不变，再精修伙伴相关状态和菜单。窗口标题与任务状态不再固定写「小远」。外观设置只更换当前伙伴形象，伙伴选择更换独立身份。

## 规范与实现

- DESIGN.md §六.7 对话框、§八动效/状态/文案、§十检查表、§十一伙伴扩展；主界面 Quiet Studio 参考实现。
- 复用 PageHeader、Button、Select、ai-elements PromptInput / Conversation / MessageResponse、既有主题引擎与 `home-caption` recipe。不新增主题、色系或局部外观样式。
- 专用 sandbox preload 仅提供伙伴窗口契约。普通应用桥只读平台标识，主窗口的通用 IPC 不开放。所有调用验证本窗主 frame，参数严格校验，状态操作有界串行。Cowork 正文不广播到伙伴窗。
- 隐藏保留 DOM、草稿与任务；停止才撤回当前回复。无模型不签发受理回执，草稿和重试请求键保留。已受理后新输入的文字不被旧请求清空。
- 中文/英文、light/dark；浏览器检查 560×640 与 448×640，热切换检查另覆盖 1280×800、1440×900、1024×768、940×700、760×700。原生 Electron 44.9.3 使用隔离 userData 与本机 SSE 夹具。
- 截图：[浅色](../companion-window-2026-10-24/light.png)、[深色](../companion-window-2026-10-24/dark.png)、[真实 Electron](../companion-window-2026-10-24/native-electron.png)。对话均来自明确的隔离夹具，不作为真实上游模型体验证据。
- Browser 插件未提供 browser skill，使用仓库 Playwright 流程。浏览器夹具只证明渲染与交互；真实 Electron 验收证明专用 preload/IPC、隐藏后台回复和草稿；两者均不证明真实上游模型质量或 Windows 系统集成。

## 证据边界与待完成项

原生验证使用真实 PiRuntimeAdapter、SQLite 和专用窗口/桥，回环上游延迟 1 秒：收起后完成回复，恢复窗口展示结果，模型请求计数 1；未发送草稿保留。没有读取用户真实会话、模型密钥或生产 userData。

暖启动快捷键 P95 目标尚未测量；原生全局快捷键已注册，但未模拟操作系统按键。输入法处理复用 PromptInput 的 composing 保护，真实中文输入法仍待人工验收。更老历史的分页、附件、任务受理与跨平台系统行为待后续阶段完成。

完整浏览器首轮两项流式测试因开发期间热更新导致执行上下文销毁，冻结源码后重跑。随后修复选择器列表缺少可访问名称、portal 不归属页面 landmark 的问题：补 List 标签与可选 Portal 容器，分别检查展开状态和关闭后的状态；闭合列表可能因组件的 typeahead 保留在 DOM，验收依据是隐藏及可访问状态而非强制卸载。G3 CPU 守护并发时一次临界失败，串行复测保持原阈值通过；未修改守护条件。生产 Knip 的存量 5 项依赖与 1 项二进制问题已在未修改 HEAD 对照复现，未加忽略。

本文件是阶段验收，不是整体产品完成或合并建议。完整范围见 [intelligent-companion.md](intelligent-companion.md)。
