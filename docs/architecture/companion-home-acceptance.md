# 伙伴首页阶段验收

日期：2026-10-25。分支 `codex/intelligent-companions`。本阶段落实用户已授权的「你的智能伙伴」主线，保留工作台；不代表完整产品交付、CI 或发版。

## 行为与复用

主窗口默认进入伙伴对话，侧栏常显「伙伴 / 工作台」。新建、搜索、项目、历史与其他功能保留，工作/对话模式属于工作台。主窗和快捷窗复用同一个 CompanionView、同一个 Pi Durable 会话与 Task/Run，不创建第二套执行或模型选择框架。模型自动使用已有配置。

React 内置 Activity 保留两个页面的 DOM、输入和滚动，隐藏时清理其 effects，重新显示时恢复订阅。长期任务由原有运行时继续。工作台的附件和富文本草稿在浏览器切页测试中保留；完整 Artifact、中文输入法的原生验收仍待完成。

伙伴身份以 UUID 为准，外观与 persona 分离。提交、停止与排队执行时核对当前身份；外部切换或延迟回执不能提交/停止另一伙伴，不能清空新的草稿。主窗与快捷窗分别按 surface + petId 存储草稿，共享已落盘消息。只允许注册的主窗/快捷窗主 frame 调用，外部窗口及子 frame 被拒绝；主窗不能调用快捷窗的隐藏行为。

主页面复用 PageHeader、Button、Select、FluidTabs 与 ai-elements；768px 阅读列，身份旁使用现有原创图集的静态 48 DIP 缩略图，不播放闲置表演。没有新增 Hero、卡片层、色系或外观设置。主题改动全部走共享 recipe 和成套主题 token，生成 CSS，没有修改既有验收基准截图。

侧栏项目空态的添加动作改用已有中性 secondary 默认按钮，不再同时出现添加项目、发送与输入焦点三处品牌蓝；保留创建项目行为。

## 原生链路

Electron 44.9.3 / Node 24.22.0 / macOS arm64 / DPR 2，独立临时 userData 与工作区，真实 Magpie 进程连接本机 SSE 夹具；未使用真实账号或上游模型。记录见 [原生报告](../companion-home-2026-10-25/native-report.json) 与 [原生截图](../companion-home-2026-10-25/native.png)。

- 七位身份在两窗同步；切换后独立草稿恢复，旧身份的提交和停止被拒绝。
- 修改外观，两窗缩略图更新，原来的 UUID 与 persona 保留。
- 主窗发出聊天，快捷窗显示同一用户消息和回复，各出现一次；快捷窗未发送草稿保留。
- 同次验收完成既有任务受理、免打扰期间继续、隐藏释放媒体、成功后完成动作、同 Task/Run 工作台展开。
- 夹具共记录 1 次聊天、1 次任务、2 次既有记忆维护请求；没有额外分类模型请求。

先构建 `bun run build:electron:dev`，准备已验证 Magpie 并启动 preview，再串行运行：

```bash
PREVIEW_PORT=5194 COMPANION_VERIFY_HOME=1 bun scripts/companion/verify-task-electron.mjs
```

不要与写入 dist-electron 的 build/Knip 同时运行。原生截图在导航选中和目标输入均可见后拍摄，不能仅以隐藏页面中的草稿值判断切页完成。该夹具证明宿主、网关、持久会话与 UI 接线，不证明真实模型性格、工具交付质量或外部副作用恢复。

- 生产 build、主进程类型、bundle-budget、常规/生产 Knip、lint、format、源码行数通过。lint 的无关存量警告与 Knip 3 项既有提示未清理。
- bundle-budget：启动依赖 109 文件 / 1.76 MiB；preload 31 文件 / 0.87 MiB；无 sourcemap。
- preload contract：446 必需 / 447 类型路径；browser mock codegen 45 文件最新。主窗明确投影同一伙伴桥接，快捷窗仍只有受限 API。
