# Pi harness 修复与清理计划

目标：harness 不阻碍 Pi 原生执行、自动压缩及长程任务。依据 2026-11-11 对 `be4c7bf8e` 的审查；用户已授权全部修复和清理。

## 实施顺序

- [x] 审批：等待审批不等于终止；并发审批独立结算；只读、内部记账、委派工具不重复审批，实际副作用仍走门禁。
- [x] Skill：运行中追加技能同步脚本白名单和根目录，初始无技能的会话也能使用后续选择。
- [x] 子代理：贯通取消，停止待启动任务和活动会话；不默认强制 30 分钟收尾；应用与主会话一致的压缩配置。
- [x] 原生完成：清理控制型研究/快捷工作流、固定轮数强制收尾和协议遗漏纠正。保留任务台账及实际交付证据，不以固定文件扩展名、轮数或评审口令阻断完成。
- [x] 压缩：模型更新必重算预算；真实 SDK 验证小窗口、连续压缩和溢出恢复。
- [x] 记忆：按 observation 修订去重；限制可选召回总等待；支持取消；压缩后重新建立注入边界，失败发送不吞记忆。
- [x] 长操作：移除 Bash 默认/最大超时覆盖以及 2000 字符分块协议和额外截断补跑；使用 Pi 原生行为。
- [x] 清理：移除不再可达的工作流扫描/整文件哈希、工具、测试夹具和文档引用；保留其他能力使用的共享实现。
- [x] 验证：回归测试、流式守护、类型检查、lint、Knip、格式、构建；真实 Electron 检查受影响运行路径。说明无法验证的外部条件。
