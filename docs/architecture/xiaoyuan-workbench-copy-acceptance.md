# 小远工作台文案与运行信息验收

2026-10-26；接续已合并的 #1334。此批保留工作台、角色、欢迎动画与气泡聊天位置，整理工作台底部信息和中英文操作提示。私有记忆依赖继续冻结。

## 改动

底部指标改为共享 Button/Popover「运行信息」，不再占用一整行技术摘要。实际零值保留，未报告的指标省略，计算逻辑不变；通用生成内容说明收进同一浮层。输入区抽出独立组件，原来的测量 ref、权限状态、待发送队列和提交/停止回调保持连接，背景外观移入主题 recipe。

提示围绕实际行为：权限显示当前确认方式，后台运行说明退出后的状态；错误提供可执行的下一步，思考与工具计数不再表示任务已完成。中英文同步，无新增权限流程、模型设置、IPC 或存储键。
