# 伙伴任务交代：阶段验收

2026-10-25 更新。在原有持久聊天窗中加入任务交代、工作区选择、近期任务状态、独立停止和同一工作台任务直达。此阶段仍未交付附件与全部产品范围，不能代替整体产品验收。

## 执行与数据边界

- 聊天仍由统一适配器拥有的持久会话承接；显式任务进入原有 Cowork → PiRuntimeAdapter → Workbench Task/Run 链路。没有独立任务执行器、分类模型调用、权限系统或全局模型设置。
- 原 Cowork 启动过程提取为共享的准备与启动入口，保留系统提示、专家、工作区、消息、模型和权限选项。伙伴任务把会话、首条消息、Task、排队 Run 与受理回执放在同一个 SQLite 事务中；提交后才启动适配器，并传入原 Run ID。
- `companion_task_admissions` 只保存身份、请求指纹和原生 ID。`petId + requestId` 唯一，相同请求重试直接返回原回执，内容变化拒绝复用；并发、回执丢失、重开和删除会话均不自动重放外部操作。重启发现未派发的旧排队运行时标记失败，由工作台显式重试。
- 模型从已经同意开启的模型服务自动分配；不写全局默认，不复制密钥。没有模型时不创建任务，草稿、输入用途、工作区和请求 ID 保留。目录可用仍不能证明真实工具或视觉能力。
- 近期任务读取同一 Task 的最新 Run；显式重试在工作台保留 Task ID。状态由原有任务事件推送，只向当前伙伴投影其拥有的任务，不广播其他伙伴的任务正文。
- 任务元数据附带主进程单调递增的序号；渲染器按伙伴缓存最新版本，包括初始化前收到的事件。较早的初始化或受理刷新结果不能覆盖新的失败状态；不增加模型调用，也不改变流式正文协议。
- 首次使用可直接打开原生文件夹选择器；只有该选择器返回的路径进入工作区服务，渲染器不能传入任意路径。取消不改变草稿，等待期间继续编辑的文字保留；隐藏工作区经用户重新选择后恢复可见。
- 草稿与请求键统一从即时引用读取，在 React 状态更新函数之外持久化；接到回执只清除对应请求的原草稿。初始化未完成时禁止编辑与用途切换，避免载入结果覆盖先前输入。
- 打开工作台复用桌宠现有的排队导航、加载确认和失败确认机制。收起窗口不停止任务；独立停止调用原生停止并取消对应运行。普通聊天窗口没有通用应用、模型管理或任意文件 IPC。

## 已验证

- 新增受理与窗口边界、原有桌宠控制与菜单、主窗口接线、分段控件：6 文件、36 项测试通过。包含事务回滚、并发去重、请求指纹、无模型、重开不重放、初始化拒绝、停止、外来身份拒绝、同 Task 重试后的最新状态、原生选择器路径来源及元数据顺序。
- 适配器回归 15 文件、162 项通过；共享选择器修复后 renderer/shared 344 文件、1867 项通过。最终完整浏览器预览 44 项通过、1 项原有跳过；任务相关用例验证初始化与受理刷新晚于失败事件时仍保留失败状态，以及首次选择文件夹、取消和等待时编辑。已有其他页面的 warn-only 无障碍抽检报告 `aria-required-children`，不计为无障碍全面通过；本任务明暗 axe 无违规。
- 前后端类型、生产构建、常规 Knip、生产 Knip 文件检查、格式、行数、文件大小与包体预算通过；启动图 1.75 MiB、preload 图 0.87 MiB。lint 退出成功，修改文件没有新增警告，不清理无关存量警告。
- 已在未修改 HEAD 复现两项旧菜单测试使用过期「展翅一下」标签；按文件大小规则移到独立菜单测试文件，对齐现有「舒展一下」，保留所有行为断言。没有删除测试或降低门禁。
- 原生验证发现开发构建错误地把 import-only 的运行依赖转为 CJS require；主进程开发脚本和开发监听现与生产采用同一外部依赖边界。真实 Electron 启动已经恢复。

## 尚未完成

本工作树起初没有模型网关原生资源，宿主 Go 为 1.26.2，与仓库锁定的 1.26.8 不一致。官方 SDK 完整 SHA-256 已核对清单通过，Go 1.26.8 已安装到临时目录；固定上游提交的 5009 个文件均已按 Git tree 逐一验证。目前原版构建正在下载锁定依赖，随后继续隔离 Electron + 本机 SSE 夹具验收。该夹具即使通过，也不能证明真实模型质量、真实上游用量或工具能力。

附件、真实输入法、其余控件的完整对比度量测、真实网关/模型/工具体验、对话状态与伙伴动作联动仍需继续。安全未派发任务的自动接续也尚未实现；当前重启后标记中断并提供显式重试，不作为完整恢复能力交付。完整产品的连续动画、Windows 窗口互动、私有记忆和主动跟进保留在 [总清单](intelligent-companion.md)，不将此阶段作为整体完成或合并建议。
