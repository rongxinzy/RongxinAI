# 气泡任务附件：拖放与粘贴

2026-10-26，基于 `215bcb35`。本阶段完成输入区任务文件的拖入与粘贴，保留原生文件选择、独立草稿、工作区、既有 Task/Run、附件授权和失败处理。记忆依赖冻结，没有修改模型配置、候选运行时或欢迎动画。

## 行为与边界

- 复用工作台 `usePromptFileDrop`、共享 PromptInput 与附件行。文件事件在输入区捕获阶段只消费一次；普通文字粘贴保持浏览器默认行为。
- 原生选择仍为原文件引用。拖放/粘贴的 File 在渲染器异步读取，每次仅一个不超过 25 MiB 的二进制 IPC；主进程异步写入既有应用临时附件目录，再产生当前伙伴的授权 ID。没有通用路径参数、base64 解码、图像解析、扫盘或哈希；UUID 文件名与独占创建阻止覆盖，授权失败删除本次临时文件。
- 草稿只保存 `id/name/bytes`。写入后的字节和路径由原有授权目录持有，其他伙伴、错误 frame 和过期身份不能读取或暂存。系统清理临时文件后仍按既有「附件已不可用」流程保留草稿并让用户重新选择，不承诺附件永久保存。
- 仍为最多十个附件；批次超数量或任一超大小时，在读文件前拒绝整批。暂存逐项进行，若后续读取/存储失败，之前已成功的附件和当前文字都保留；锁防止原生选择与连续拖放重叠。迟到结果不越过身份切换。
- 聊天收到附件仅提示「处理文件请切换到交代任务」，不会自动切换、消耗一次聊天或声称模型能看图。任务图片和真实视觉模型的能力验证属于后续范围。
- 实际截图发现空任务区被压成细条、附件第二行底部裁切。空任务列表不再重复输入提示；真实消息/任务区保留最小可读空间，并复用共享滚动焦点 recipe；两行附件完整展示。没有新增色系、外观开关、说明卡或样式例外。
