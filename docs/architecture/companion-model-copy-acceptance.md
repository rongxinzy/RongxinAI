# 伙伴产品的模型设置文案阶段

本阶段延续「你的智能伙伴」方向，保留工作台、统一模型服务和原有三段设置结构。模型服务商不再与通信渠道混称；启用、隐私与故障说明只保留用户判断所需的信息。

## 实现范围

- 「渠道与模型」改为「服务商与模型」，服务商的添加、编辑、删除、状态与名称同步改称。通信渠道不改名。
- 默认模型说明改为实际优先级；空目录给出添加服务商或加载本地模型的下一步。伙伴不增加独立模型设置。
- 停止状态的高级设置说明指向确实存在的「服务商与模型」，不再引用已经移除的「服务」分段。编程工具接入说明缩短为实际入口。
- 启用服务仍明确告知读取与同步已接入工具配置、订阅账号独立同意、遥测与局域网访问默认关闭。订阅凭据与重启中断说明保持。
- 脱敏文案说明「识别到的」数据会被替换，不宣称所有敏感内容都能被识别；没有改变网关处理。
- 40,035 字节的 `magpieTranslations.ts` 按模型设置、外部工具、服务商与路由用量拆成四个职责模块，原路径保持薄入口。中英文各 322 键完整保留，变量占位符未变。30 组审阅项中实际修改中文 29 项、英文 27 项，其余文案已与目标一致。

## 本地记忆服务与待授权原型

私有记忆服务新增有界、按所有者过滤的检索，已确认事实与候选分开；不返回个人共享记忆或另一伙伴的记录。现有界面的遗忘增加所有者绑定的持久意图，待同步候选被删除后重复请求可以确认原操作，不重建已撤回内容。记录仍在时恢复会继续撤回，不能仅凭意图标记伪造完成。

聊天自然语言记忆工具尚未接入生产会话。自动审批拒绝了将查询、保存、修改、遗忘工具启用到模型的改动，理由是缺少明确的私有记忆处理与删除授权，已向用户发出确认。未经答复不启用，也不通过其他路径绕过。

原型只在本地 Faux 模型、合成事实、临时 SQLite 与本地记忆服务中验证。19 项通过，其中包括实际原生工具 Schema 校验、所有者注入拒绝、跨伙伴已知 ID 拒绝、离线状态、写入/遗忘已生效但 Durable 回执未提交时的重开恢复。该证据不等于生产工具已接入或真实模型使用质量通过。

原型从产品源码移出，保存在 `/tmp/companion-memory-tools-awaiting-authorization.patch`，SHA-256 `51da4fdd3ebd0bae9ac0e065e66b976856aa98f981edd367602cffe55fadaaed`；不加入构建入口、门禁白名单或第二执行框架。
