# 七位伙伴开场：阶段验收

2026-10-24。按用户「开场动画也要换，画一个七个宠物欢迎用户的界面」的要求，替换原粒子标志开场。七位伙伴围成浅弧，小远居中，配一句「你好，见到你真好。」和实际初始化状态。工作台保留。

## 实现与范围

- 使用内置 `image_gen.imagegen` 绘制原创透明群像，最终 PNG 为 1899×828、1,532,158 字节。直接保留工具输出，没有程序化编辑或重编码。提示词与修整记录在 [素材说明](../../src/renderer/assets/desktop-pet/welcome-prompt.md)。
- 群像以 240ms 淡入与短距离位移进场，初始化结束后 200ms 退出。没有最低展示时长，图片未加载或加载失败也不会阻塞；减少动效时静态显示并立即退出。初始化出错显示准确状态，然后进入原错误页。
- 这是一幅有入场过渡的群像插画，**不是七个角色逐帧挥手的连续动画**。真正全身连续媒体仍在完整产品清单中，不将这次开场计为该项完成。
- 外观来自 `home-studio` recipe，注册 `welcome-screen/title/art` 三个 hook；所有主题共用这套结构，媒体保留内容原色。中英文文案进入共享词典。语言初始化完成会通知已挂载界面，不必等其他启动步骤完成。
- 触及的 App 文件原超过 5000 token，按仓库规定将原 toast 生命周期与本地推理休眠生命周期机械提取为两个 hook；没有改变工作台的任务创建或推理行为。对应行为测试与原新会话守护均通过。
- 补齐伙伴对话窗 preload 的开发构建入口与生产 Knip 入口，使独立打包入口可被检查；未增加忽略、基线或门禁豁免。

## 验证边界

Browser 插件没有可用的 browser skill，使用仓库 Playwright 流程。图片缺失测试只中断真实图片请求，保留开发模块请求；主题切换由实际 themeService 执行，没有直接改 DOM 冒充主题更新。

原生 Electron 使用本机编译产物与独立临时 userData；仅在隔离测试实例中延迟模型目录回执以截取欢迎页，放行后进入工作台。没有读取用户真实会话、生产模型密钥或默认 userData；sandbox 下 renderer 没有 Node require。该检查证明原生初始化接线，不证明真实模型质量或系统窗口攀爬。

完整产品仍按 [总清单](intelligent-companion.md) 推进；这次开场不代表发版或整体交付。
