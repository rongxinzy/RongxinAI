## 改动

- 使用「长期记忆」「待同步」「恢复使用」「不保存」等直接动作和状态，去掉受控、投递、传播等内部术语。个人与工作区范围的区别留在需要选择的编辑表单。

## 当前固定运行时的缺陷

真实 macOS Electron 验收发现：全局记忆先软删除，再永久删除时，固定的 CJK 运行时 `v1.20.0-zhiyuan.4` 返回 HTTP 404。数据仍在运行时内，投影保持待同步。因此不能把 404 当作成功，也不能宣称产品永久删除已经修复。

官方已有 [db69819 上游修复](https://github.com/Gentleman-Programming/engram/commit/db69819e446386a84e6219584008b9d0c16bc653)：仅在显式硬删除事务内允许读取已软删条目，普通读取仍隔离它们。已在固定版本的临时源码上复用该 MIT 补丁，保留许可证，并增加物理删除、会话引用、同步标记、HTTP 授权和错误边界测试。红灯可复现，修复后完整 `go test -mod=readonly ./...` 通过；存储覆盖率 79.2%、服务端 70.7%。

全覆盖命令的 CLI 包失败在干净固定版本同样复现（宿主 Go 1.26.2），没有单项测试失败；未绕过、修饰或把它计为通过。历史补丁包位于 `/tmp/engram-hard-delete-review-20261025/`，包含许可证、来源、补丁和测试日志。按用户后续指示改为先升级官方最新版，有缺口再维护自己的 fork，旧版本补丁不作为最终发布路径。
