# 模型服务商编辑：阶段验收

本阶段继续「你的智能伙伴」的模型入口整理，保留工作台、现有统一选模与服务商协议。它接续[模型文案阶段](companion-model-copy-acceptance.md)中明确未验收的编辑弹窗，不代表整个模型设置或伙伴产品已交付。

## 改动与原因

原弹窗的首选、备用标记只有 10px，部分模型操作命中区只有 16–20px；协议选择器还会显示内部枚举值。现改用共享 Field、Input、Textarea、Select、Button、Alert 和 lucide 图标。弹窗宽 576px，字段纵向间距 16px；表单正文独立滚动，底部保存/取消始终可达。模型列表每页十项，操作为 32px；长 ID 换行，隐藏页的模型不会丢失。

中英文标签缩短为模型、备用模型、首选等直接名称。文本模式保留原始输入，支持换行、中英文逗号和顿号分隔；备用列表仍独立编辑。协议名称不再重复接口路径。空密钥仍沿用原有省略语义，没有读取或回显保存的密钥。

保留预设、自动发现、替换/追加/保留现有列表、首选排序、备用切换、移除和文本模式。连接反馈按实际结果显示，不在等待用户处理冲突时宣称已经自动填入。修改表单会清除旧连接结论；关闭后重开或更换服务商时，旧请求不能覆盖当前表单。保存期间阻止关闭和重复提交，失败保留草稿供显式重试；不把它声称为跨进程持久幂等保证。

原文件 29,376 字节，按连接字段、发现反馈、模型列表和表单生命周期拆分，原路径保留薄入口。新增模块均小于 20,000 字节，无新依赖、IPC、存储键或模型执行框架。

服务商保存、启停和删除失败仍使用统一错误提示，并保留原始诊断；这些可以重试的用户操作改以 `ModelSettings` 的 `warn` 级别记录，其他调用默认的 `error` 级别不变。共享提示新增可选日志级别，不改变错误提示外观。单测同时断言控制台和主进程日志桥的诊断、用户错误提示保留；浏览器断言注入保存超时只产生一次对应 warning，通用 console.error/pageerror 门禁保持不变。另补齐工具超时、工具权限及执行步数到限的三组中英文词条，并遍历全部错误分类核对可读文案。

组合状态实测发现共享 Alert 的浅色错误说明仅 4.2958:1。按 DESIGN.md 的既有正文门槛，先记录规范，再让共享 `alert-destructive-description` 直接使用原有 `destructive` 色，去掉 90% 混色，重新生成明暗主题。没有新增颜色或局部覆盖。
