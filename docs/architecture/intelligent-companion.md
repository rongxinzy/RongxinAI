# 你的智能伙伴：实现与验收清单

本轮方向：让伙伴陪用户交代、推进和接续事情，保留完整工作台。用户已授权按完整规划实现。本文件跟踪全部范围；基础接线、单测或某一阶段完成不等于产品交付，不代替发版与业务验收。

基线：2026-10-24，origin/main `ee9abc6f`。七种形象已有多姿态图集和时间驱动编排；没有真实全身连续视频、外部窗口攀爬、伙伴独立智能会话或快捷对话窗。dsh-pet 对照版本 `b292803d`（MIT），其透明视频播放机制可复用；模型执行沿用本项目统一内核。

## 产品契约

- 独立 `petId` 是伙伴身份，`characterId` 是形象。换装保留历史，切换伙伴不串对话、任务或私有记忆。初期只激活一个伙伴，其余休眠。
- 小远沉稳清晰；游栗好奇灵活；团团耐心温和；绵绵细致；竹栗轻松务实；云墨富有想象；麦小干脆有行动力。性格不改变权限与交付标准。
- 自然聊天由伙伴持久会话承接；实际任务进入现有 Task/Run 与工作台，同一请求 ID 去重。模型不重复分类、聊天、执行同一任务。
- 所有执行通过 PiRuntimeAdapter。Durable 管收件、对话和恢复；Task/Run 管业务事实，现有自动化管触发，现有记忆管长时记忆。不得形成另一套权限、调度或记忆引擎。
- 模型优先使用可用的全局默认项，否则自动选择现有合规配置；不写全局默认、不复制上游密钥、不替用户开启服务或账号发现。路由组内部回退仍由网关负责。
- 模型目录不证明健康或工具能力。文本、工具、视觉分别验证；故障冷却、配额和实际请求结果决定降级。没有模型时保留草稿与本地动画，有模型后恢复相应能力。
- 桌面进程运行时可后台继续；关闭应用或关机不会继续执行。重启恢复待办，不承诺桌面关闭后的全天在线。不可重放的外部操作失去回执后不能盲目重试。
- 主动提醒以已授权任务、明确约定和真实阻塞为依据。免打扰控制打断，不终止已授权任务。实际用量通过现有模型网关记录，不杜撰价格。

## 验收边界

1. 持久会话先完成真实落盘、关闭重开、同请求去重、停止和失去模型的行为测试；再验证真实网关及真实模型。
2. 快捷窗须实测输入法、键盘、隐藏与停止、重复提交、附件、工作区和工作台同任务展开。启动 P95 ≤200ms 是目标，须记录样本与环境后才能报通过。
3. 新页面按 DESIGN.md 十节逐项自查，明暗、窄窗、长文、主题热切换、焦点与草稿保留。浏览器 mock 与真实 Electron 分别报告。
4. 动作须观看实际媒体，确认肢体连续、起收势和触点，不以序列时长或帧率替代判断。验证遮挡、越界、减少动效与长时资源占用。
5. Windows 在 100–200% 及混合缩放、多屏与系统窗口状态下实测。本机 macOS 的纯几何测试不能替代 Windows 原生验收。
6. 自动选模验证禁用/未同意服务不启动、策略拒绝、无默认、默认失败、路由组、配额、模型失效及恢复。无工具能力证据时不能宣称能执行任务。

阶段顺序：持久与选模验证 → 快捷交代与身份 → 动画与窗口互动 → 记忆与主动跟进 → 全链路稳定性验收。各阶段均保留未交付项，整体目标完成前不将本清单缩减为当前易完成的部分。

## 优先复用的现成能力（2026-10-25）

- 执行、持久会话和业务任务继续复用现有 Pi、Durable 与 Task/Run，不另建执行框架。真实目录的未知能力数组是本地适配语义错误，已修复；不是缺少新的选模库。
- 动画播放先复用已获授权的 dsh-pet MIT 机制；连续骨骼动作可评估 [Rive Web runtime](https://rive.app/docs/runtimes/web/web-js) 和 [数据绑定](https://rive.app/docs/runtimes/web/data-binding)。运行库消费已经制作的 `.riv` 素材，不会自动生成七位伙伴的动作。尚未加入依赖、迁移素材或把候选方案当成交付。
- Windows 窗口接口可评估 [Koffi 的 Win32 回调绑定](https://koffi.dev/callbacks)，减少手写原生绑定；窗口遮挡、支点、攀爬和动作协调仍需实现。优先在隔离 helper 验证枚举及事件回调，主进程保留 Electron 窗口所有权；Windows x64/arm64 打包、回调生命周期、DPI 和实机行为通过前不认定可用。

## 已完成的基础验证（2026-10-24）

- `src/main/companion/`：身份仓库、独立 persona、Magpie 自动分配与 Pi Durable 原生存储。`PiRuntimeAdapter` 通过服务绑定持有该后端，不安装独立执行工具；退出走 `close` 保存待恢复输入，用户停止才撤回。
- 存储路径为 `userData/companions/<petId>.sqlite`。路径使用 UUID 与解析后的真实目录，进程内拒绝重复所有者；切换形象不会改变路径、身份或 persona。
