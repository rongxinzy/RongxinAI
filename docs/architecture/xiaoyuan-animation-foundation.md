# 小远动画基础

本分支基于 `origin/main` 的 `50aee4297b23a83b6f0a76ea4f58eab839a8a13a`，先整理形象和动画；完整伙伴开发仍保留在 [草稿 #1333](https://github.com/rongxinzy/RongxinAI/pull/1333)。这一步没有升级记忆依赖，也没有改模型配置或执行内核。它尚不是完整的伙伴发布候选。

## 形象与动作

- 第一版图集保持 SHA-256 `2883fbb9a6f09a493769294fc8993cf96e6992ad5dc4a74c0968c56a3a586465`，中性静态姿势与原图在 192 DIP 逐像素相同。
- 24 段 512px、30fps 原形象透明动作，完整性清单位于 `src/renderer/assets/desktop-pet/motion/xiaoyuan-original/manifest.json`。验收比较每段视频、掩码、加载图的哈希、时长和帧数。
- 播放器最多持有两个视频槽，提前解码下一段，在真实结束事件交接；保留 120ms 混合。睡眠接醒来，不因预测时长提前截断。
- 任务错误、待确认和思考中断表演；隐藏、减少动效及销毁释放视频源。损坏媒体退到可见静态形象。
- 移植部分保留 dsh-pet 作者、固定来源提交和 MIT 许可，完整许可在 `public/licenses/dsh-pet.txt`。
- 六位隐藏伙伴的代码和静态图集仍在，旧形象设置只在显示时投影为小远；它们的未批准视频没有加入本分支。
