# 技能创建与连接器授权文案

2026-10-26，基于 `231769df`。本阶段检查实际「专家 → 技能 / 连接器」入口，精修创建表单与授权说明；工作台、小远、七位欢迎、其余六位隐藏规则、记忆依赖均未修改。不是全产品文案或整个连接器目录的最终验收。

## 改动与原因

- 英文新建技能原有中文模板、中文按钮与缺失标识错误。现在字段、模板和错误均走中英词条；去掉「规约 / SOP / 最佳实践」等不帮助填写的表述，用「标识、名称、用途与使用时机、执行说明」呈现实际输入。
- 保存 API 会写入名称、用途与文件头；原编辑器却生成完整 SKILL.md，导致嵌套头部。现只编辑 Markdown 正文，沿用原 API，不新增执行或保存框架。默认模板描述材料、步骤和输出，保留用户自行编写的内容。
- 创建弹窗复用 Dialog、Field、Input、Textarea 和 Alert；标签关联输入，控件与正文至少 14px，按 16px 字段间距排列。长正文只滚动表单，保存/取消保持可达；保存期间锁定输入与关闭，重复提交不另发请求。主题或语言热切换不清空正文、焦点或选区。
- 连接说明改为事实：授权范围决定可访问的数据和操作；工具调用所需内容会发送服务方；移除本应用连接与服务方授权管理分别说明。七份实际加载的 metadata 同步修改，账号/商业合同/Token 约束保留。GitHub 的展示文案按既有 Token 分支修正，不再误写 OAuth。
- OAuth/CLI/Token 的目录入口为常显「连接」，普通本地安装仍为「安装」。已有配置显示「已添加」，不据配置存在宣称连接健康。操作按钮复用共享 outline，避免目录每行都使用品牌蓝。授权窗用 512px 共享弹窗和字段文本，移除四段说明外的嵌套卡片。
