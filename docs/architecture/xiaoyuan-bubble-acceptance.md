# 小远：头顶气泡、聊天与任务交接

2026-10-26。基于 `origin/main` 的 `50aee4297b23a83b6f0a76ea4f58eab839a8a13a`，接续[原形象动画](xiaoyuan-animation-foundation.md)与[七宠欢迎](xiaoyuan-welcome-acceptance.md)。日常只开放小远，另外六只的形象、身份与完整草稿保留。欢迎原图、文案与入退场不变。

## 本次实现

- 点击小远，在角色上方打开可输入的铅笔气泡；屏幕顶部改放下方。输入时暂停漫游，Escape 收起并保留草稿。桌宠关闭时，既有全局快捷键仍能在光标附近打开同一个窗口。
- 纸面只由手绘轮廓填充，内容层透明，修复矩形内容底色遮住上下边缘、露出直角的问题。输入只保留下划线焦点，不叠矩形焦点框。明暗图见[浅色](../theme-previews/xiaoyuan-bubble-2026-10-26-light.png)、[深色](../theme-previews/xiaoyuan-bubble-2026-10-26-dark.png)。
- 气泡共用一个输入框，以「聊天 / 交代任务」选择用途。主窗口保留工作台，不嵌伙伴聊天，不重复读取伙伴对话。
- 聊天复用统一执行适配器拥有的持久会话，自动选择现有模型服务中的可用模型，不写全局默认、不新增伙伴模型设置。没有模型时保留原文与附件，不伪造回复或任务回执。
- 实际受理后才进入思考，实际完成后短暂高兴；工作台失败、待确认与运行状态优先。隐藏与免打扰不补播旧表演。
- 任务进入现有 Session/Task/Run 管线；回执持久化后才启动，重复请求复用原回执。气泡任务行打开同一个任务；先刷新工作区，让新选文件夹在侧栏正确选中。停止按钮停止对应运行。
- 修复已有任务打开后被全局默认模型检查带去设置页的问题：工作台初始化不再强制模型设置，新任务提交仍保留原有可用性检查。原有会话动作按职责提取，保留启动取消、续聊、排队、恢复任务及权限行为。
- 附件支持选择、拖入与粘贴；图片处理走既有有界 Worker 池。长名称在详情浮层内换行，移除按钮包含对应文件名描述。
- 快捷键设置显示全局打开键，阻止其他动作占用；中英文设置说明按真实动作缩短，关于页使用「你的智能伙伴」。
