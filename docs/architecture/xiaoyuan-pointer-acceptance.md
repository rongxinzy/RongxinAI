# 小远拖动、点击与窗口层级检查

2026-10-26，基于 origin/main `b09ed1c7`。范围仅为桌宠交互修正；保留小远、七位欢迎图、聊天和任务原有能力，不扩展功能。

## 产品检查与处理

| 场景 | 原行为与原因 | 修正 |
| --- | --- | --- |
| 单击 | 松手即开聊天；双击还会另开工作台，两条事件互相叠加 | 单击只有角色动作，无聊天或文字气泡；双击只开聊天 |
| 拖动 | 按下即挪动，终点距起点小于 5 DIP 就算点击 | 5 DIP 内不挪动；一旦越过阈值，即使绕回原点也不算点击 |
| 指针取消 | 取消和捕获丢失走普通松手路径，可能误触点击或甩抛 | 显式取消，只结束拖动、保留位置 |
| 窗口层级 | 角色和聊天都 `alwaysOnTop: true`，持续覆盖其他窗口 | 两者使用普通层级；角色继续不抢焦点，其他窗口可自然覆盖 |
| 右键 | 原生菜单展开后仍可能漫游或甩抛 | 菜单展开时暂停移动，退出后按可见性和设置恢复 |
| 任务直达 | 双击和单击职责冲突 | 保留右键「查看待处理任务」及失败确认语义；无任务时打开工作台 |
| 被挡住或暂时不想看 | 已有快捷键、托盘、收起、免打扰和重置位置入口 | 继续复用，不增加额外置顶、穿透开关或模型能力 |

角色本体可以命中，透明区域继续穿透。拖动可跨显示器，位置受工作区约束；屏幕移除时收回可见区域。减少动效时停甩抛和漫游。既有「应用全屏时隐藏」只检测本应用，不能宣称检测其他 Windows 应用全屏。
