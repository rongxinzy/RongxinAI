# 会话进入抖动修复与验收

## 触发条件与回归来源

进入历史会话时，先显示末尾 30 条消息，再自动前插 50 条。分页可能截断一个轮次；补齐后轮次 ID 不变，但真实高度增长。青眼白龙会话原本会短暂离底 **976px**，龙与地下城场景会话为 **1474px**，随后又拉回。

已隔离出的回归来自 [PR #796](https://github.com/rongxinzy/RongxinAI/pull/796)，merge `47b60547569cfbc0ba8079854d12a6dc7f99bcc6`，直接提交 `48f88cd90659478f14f9821502309376f80e2c4d`。它把每次提交后的初始跟随校正限制为首次执行；同 PR 后续 `37ecc385` 补上首尾 ID 改变的校正，仍遗漏同一轮次的重新测高。#363 的进入预取是触发条件；#977 的详情预加载不是本次虚拟列表回归的来源。

TanStack `resizeItem` 先更新尺寸缓存并请求滚动补偿，再调用 `onChange`。原实现先写 scrollTop，此时 DOM 撑高容器仍为旧高度，浏览器截断目标；随后容器与行位置更新，错误位置跨帧可见，下一帧重试才恢复。扩展验收还发现：前插提交中新增行收缩、保留末行增高时，旧尺寸缓存与实际溢出内容不一致，也会暂时离底。

历史组件源码 A/B 固定当前 React/TanStack 依赖及相同几何序列：#796 前 `c196d6f1` 稳定；`48f88cd9` 跳 976px；只恢复每次 commit 校正便稳定；`37ecc385` 仍跳；当前组件调整几何/滚动顺序后稳定。这是组件源码隔离与单变量验证，**不是完整历史 Electron 应用及旧依赖的逐提交二分**。

另外，实际验收发现已持久化产物的卡片在异步文件检查及历史声明加载后才出现，产生独立的 **36.25px** 内容位移。此项不归因于 #796。

## 实现

1. `VirtualizedTurnList` 在写滚动补偿前同步撑高容器和已挂载行位置；不需要补偿的测高仍通过 onChange 同步。
2. 在已有布局测量循环中，将当前已读出的真实行高同步给 virtualizer，覆盖保留行内容更新。保留用户向上浏览的锚点规则，不恢复每次 render 强制贴底。
   虚拟撑高容器及行禁用 transition。减少动效的全局规则给所有元素设置 `transition-duration: 0.01ms !important`，与默认 `transition-property: all` 组合后，几何更新也会过渡。实测容器 inline height 已为 4163px，computed height 却仍为 7602px，使滚动读到旧几何；禁用虚拟几何过渡后同步生效。未改变主题 recipe 或全局减少动效规则。
3. 提取原持久化产物 seed 为独立 hook。检查期间复用同一 `ArtifactPreviewCard` 的 disabled 状态保留几何，检查完成原位启用；确认缺失仍移除，超时/未知仍沿用现有策略，过期会话回调被取消。
4. 按最终答复中的绝对路径或工作区 inline-code 文件路径定位已知产物，避免声明位于未加载历史页时卡片换位。使用统一路径解析，按完整路径匹配；不按相同 basename 合并不同目录，不创建新的产物候选。

没有新增等待显示、关闭历史预取、取消虚拟化、隐藏已就绪内容或每帧强制贴底。主进程、IPC、SQLite、权限及预览隔离边界没有变更；无需数据迁移，回滚可直接撤销本提交。

## 真实 Electron 验收

基于 main `a1696f2d` 的独立工作树，Windows Electron/Vite 开发实例，Vite 5175 / CDP 9222，长安风物主题。沿用真实数据库，以侧栏真实点击进入 4 个会话；每次先离开再进入。每次从点击前开始逐 rAF 采样，覆盖 30 → 80 条历史补入；CDP screencast 记录实际画面。未发送模型请求，未创建、编辑或删除历史消息。

矩阵为 4 会话 × 1280×800 / 900×700 × light/dark，共 16 次。离底距离为 `max(0, scrollHeight - scrollTop - clientHeight)`；锚点比较相邻采样中同一可见段落且高度不变的顶部位置。小数几何不等同于可见的往返跳动，rAF 也不等同于屏幕呈现；已结合实际录帧审看。

| 会话 | 原行为 | 修复后最大离底 | 修复后最大锚点变化 |

| 青眼白龙 | 976px 往返跳动 | 0px | 0px |
| 龙与地下城场景 | 1474px 往返跳动 | 0px | 0px |
| 项目说明会话 | 首轮修复后仍有 889px 离底，另有产物卡片 36.25px 插入 | 0px | ≤0.25px |

- 12 个文件、57 项测试通过：虚拟列表 unit/integration、历史分页、轮次高度、产物 seed/轮次关联、TurnBlock 和产物可用性/卡片交互。

- 产物覆盖首帧禁用卡片、同节点原位启用、确认缺失不发布、切换会话取消过期结果、未加载声明页的最终答复定位及不同目录同名文件不误配。
