# 专家管理与自动化任务界面优化说明

## 背景

本次调整统一了专家页、技能管理、MCP 管理和自动化任务页面的视觉层级，重点解决标签样式不一致、工具栏与内容区割裂、任务列表信息密度不足，以及全局历史与任务详情历史重复实现的问题。

## 专家管理

### 顶部标签

- 专家、技能、MCP 使用统一的胶囊标签样式。
- 标签列表与页面内容采用相同的左右边距，避免标签与下方内容错位。
- 移除标签下方多余的分隔线，使用激活项阴影表达当前选中状态。

### 技能与 MCP 工具栏

- 说明、搜索、二级标签和 MCP 市场分类筛选统一放入同一个 `Card`。
- 二级标签复用顶部胶囊标签的外观和激活态。
- 工具栏与列表区在同一张卡片内，使用 `Separator` 分隔。
- 外层专家标签内容区不再滚动；只有卡片下方的列表区可滚动，因此工具栏始终可见。
- 技能页的新增菜单保留溢出显示能力，不会被工具栏容器裁切。

## 自动化任务

### 任务列表

- 定时任务由表格改为横向任务卡片，名称、计划、状态、启停开关和更多操作在一行内展示。
- 启用任务后的下次执行提示与计划信息同行显示，避免提示出现或消失时改变卡片高度。
- 任务名称作为主要对齐锚点，卡片内容保持垂直居中。

### 运行历史

- 全局运行历史与任务详情运行历史复用 `AllRunsHistory`。
- 全局历史读取全局运行记录；任务详情传入当前任务后只读取并加载该任务的运行记录。
- 历史表格使用固定三列布局：任务标题、执行时间、状态。
- 状态表头与状态胶囊按同一中心线对齐，保持不同窗口宽度下的列对齐稳定。
- 删除已被复用实现替代的 `TaskRunHistory`。

## 交互与数据边界

- 本次仅调整渲染结构和既有数据读取路径，不修改定时任务定义、任务执行逻辑或持久化数据结构。
- 技能与 MCP 的搜索、安装、启停、编辑、删除和市场筛选行为保持不变。
- 任务详情的历史筛选、加载更多、查看会话和失败详情行为沿用全局历史组件已有实现。
