六条原则

  1. 一屏一个重心。首页的重心是输入岛，其余元素降一级。
  2. 品牌蓝是信号，不是装饰。只用于可执行的主动作、焦点与运行状态。
  3. 层级靠灰阶与字重。三级文字色 + 400/500/600，不靠字号跳变。
  4. 用面分区，不用线。窗口底色 + 一块抬升的内容面板。
  5. 同一行高、圆角、左边线。32px / 8px / 16px 图标，文字起点对齐。
  6. 次要信息按需出现。时间、次要操作在 hover / focus 时显示。
