| 问题 | 证据 / 影响 |

## 1. 设计目标与原则

1. **人话优先**：档案条一句概括本机能力；引擎型号、GPU 编号、上下文、量化、带宽公式仅在「详细」。
2. **结论统一**：**流畅 / 可用 / 不推荐** + **可用于智能体任务 / 仅适合对话** + 速度 **生成很快 / 正常 / 偏慢 · 约每秒 N 字（估算）**。
3. **真实产品档位 + 单卡兼容**：64GB + 双 4060M 8GB、64GB + 双 4090M 16GB、64GB + 双「16GB 移动版独显」（具体 SKU 待定）；检测为单卡时仍走同一套估算与策展映射。
4. **双卡放置（P0）**：单卡能放下 → 不分卡；第二卡留给并行第二模型；仅放不下才跨卡切分（详细区说明）。
5. **推荐加载默认值（估算用）**：上下文 **40K（40960）**、KV **q8_0**（与 `applyAutomaticLlamaCppServiceDefaults` 对 NVIDIA 的默认一致）；权重大小 = GGUF 文件大小。
6. **向量/embedding**：不进市场精选；**自动安装与 GPU 分配**在后台管理（本地页「详细」可见）。
7. **安装包边界**：应用内 **不提供** 安装/切换 lite·cpu·cuda 运行时；空态引导 **官网下载对应安装包**。
8. **下载源**：默认 ModelScope，失败自动 hf-mirror；默认 UI 只显示「下载中」，手动换源在 **高级设置**。

## 6. 智能体可用性（实现依据）

逻辑与 `assessLlamaCppAgentEligibility`（`src/shared/llamacpp/agentEligibility.ts`）一致：

| 常量 / 规则 | 值 |
| --- | --- |
| **工作模式最低上下文** | `LLAMACPP_AGENT_MIN_CONTEXT_WINDOW = **32768**`（32K tokens） |
| **判定为可用于智能体** | 运行时上下文 **≥ 32768**，且训练上下文 **≥ 32768**（若训练上下文已知且小于 32768 → 不可用于智能体）；运行时未知 → 视为不可用直至重新加载并声明上下文 |
| **产品推荐加载默认（估算显存用）** | 上下文 **40960（40K）**；KV **q8_0**（与 NVIDIA 默认服务配置一致） |

**UI 映射**：

| 标签 | 条件（在推荐 40K + q8_0、单卡可放下前提下） |
| --- | --- |
| **可用于智能体任务** | 预估可加载 40K 且模型训练上下文 ≥ 32768 |
| **仅适合对话** | 单卡仅能较低上下文（如 8K–16K），或训练上下文小于 32768，或 8GB 卡无法同时满足 40K+q8_0 + 权重 |

**8GB 卡（4060M）**：Qwen3-8B Q4 在 40K+q8_0 下显存紧张 → 优先标 **仅适合对话** 或改推 **Qwen3-4B** 进精选。

## 9. 估算与数据契约（实现指引）

### 9.1 显存与放置

- **权重 ≈ GGUF 文件大小**；推荐估算场景：**上下文 40960、KV q8_0**。
- **全 GPU 加载**：系统内存 offload **0**（UI 写「未使用 CPU 卸载」）。
- 单卡足够 → 不分卡；不足 → 跨卡切分 + 速度惩罚（§9.3）。

### 9.2 示例自洽

**A · dual-4090-16g · Qwen3-8B Q4_K_M · 40K · q8_0 · 单卡**

| 项 | 值 |
| --- | --- |
| 文件 | 5.0 GB |
| 权重 | 5.0 GB |
| KV | ~1.6 GB |
| 缓冲 | ~0.4 GB |
| 单卡合计 | **~7.0 GB / 16 GB** → **流畅**，**可用于智能体任务** |
| 速度中心 | 345.6÷5.0 = **69.1 tok/s** → 区间 **59–79**（±15%）→ **生成很快 · 约每秒 69 字（估算）** |

**B · dual-mobile-4060-8g · 同模型 · 40K · q8_0**

| 项 | 值 |
| --- | --- |
| 单卡合计 | **~7.0 GB / 8 GB** → 余量不足 → **可用** 或 **仅适合对话**；精选改推 **Qwen3-4B** |
| 速度中心 | 153.6÷5.0 = **30.7** → 区间 **26–35** → **正常 · 约每秒 31 字（估算）** |

**C · dual-4090-16g · Qwen3-14B Q4_K_M · 8.6 GB 文件**

| 速度中心 | 345.6÷8.6 = **40.2** → 区间 **34–46** → **正常 · 约每秒 40 字（估算）** |
| 显存 | ~11.5 GB 单卡 → **可用于智能体任务** |

### 9.3 带宽公式与区间（统一规则）

```text
η = 0.6
effective_GBps = gpu_peak_bandwidth_GBps × η
center_tok_s = effective_GBps / file_size_GB
display_low  = center × 0.85
display_high = center × 1.15
```

（等价于 `center = effective_GBps × 1024³ / file_bytes`。）

| 档位 | 峰值带宽 (GB/s) |
| --- | --- |
| RTX 4060M | 256 |
| RTX 4090M | 576 |
| 16GB 移动独显（待定 SKU） | **TBD**（实现时按 SKU 表，流程同左） |

**跨卡切分**：`center × (0.55–0.75)` 后重新套 ±15%。

### 9.4 速度人话（默认视图）

| center_tok_s | 档位 | 展示 |
| --- | --- | --- |
| ≥ 55 | 生成很快 | 约每秒 **round(center)** 字（估算） |
| 28 – 54 | 正常 | 同上 |
| \< 28 | 偏慢 | 同上 |

详细区可展示 tok/s 区间；**禁止**默认视图写 tok/s / GPU 编号。

### 9.5 目录数据（P2 预留）

- `capabilities[]`：`chat` `reasoning` `ocr` `asr` `tts` `video` …
- `curatedByTier[tierId][]`：仅对话模型 ID，**不含 embedding**
