# web-event

单页活动邀请函：抬头、倒计时、时间地点、当天流程、回执表单、页脚。单文件、离线自包含，双击即可打开，不需要构建、不需要联网。

## 形态

- 结构、样式、交互已经做死：`<style>` 与 body 里的骨架不要动。
- 所有文案、时间与配色集中在文件里唯一的 `TEMPLATE` 对象中，位于 `<script>` 顶部的「可编辑区」。
- 交付方式：复制本文件 → 只改 `TEMPLATE` → 其余保持原样。改完不要重写结构，也不要动渲染层。

## 适合

生日、婚礼、乔迁、同学会、小型发布会的在线邀请与回执收集。

不适合：对外的商业活动落地页（用 `web-product-launch`）、需要提交到后端的报名系统（本模板的回执只在前端切到完成态，不发请求）。

## 字段说明与约束

### `meta`

| 字段 | 说明 | 约束 |
| --- | --- | --- |
| `lang` | 文档语言 | `zh-CN` / `en` |
| `title` | 浏览器标签标题 | 不超过 40 字符 |
| `description` | 页面描述 | 不超过 80 字符 |

### `theme`

配色角色，留空即沿用 CSS 默认值。默认是深梅黑底 + 干玫瑰强调：

| 字段 | 角色 | 默认 |
| --- | --- | --- |
| `night` | 页面底色（也是顶部渐变的落点） | `#160f11` |
| `panel` | 回执区底色 | `#1d1418` |
| `ink` | 主文字 | `#f2e8e6` |
| `muted` | 次级文字、未输入字符 | `#a6888c` |
| `faint` | 三级文字（倒计时单位、页脚） | `#7a5f64` |
| `rule` | 细分隔线 | `#2f2226` |
| `ruleStrong` | 输入框下划线 | `#47333a` |
| `rose` | 唯一强调色（倒计时数字、流程时间、选中态、按钮） | `#e0a1a8` |
| `onRose` | 玫瑰底上的文字 | `#1a1012` |

这个模板是**夜色请柬**，深浅色锁定在深色一侧（`color-scheme: dark`），没有浅色版本。要浅色请柬只能在同一语言内换色，不要改成白底。错误提示色 `--danger` 写在 `:root` 里，不在 `theme` 中。

### `event`

- `eyebrow`：抬头小字，不超过 14 字符（11px、字距 0.3em、转大写）。全页只有这一处小标签。
- `name`：活动名，不超过 20 个汉字（clamp 32-49px 衬线，超过会到第 3 行）。
- `occasion`：一句副题，不超过 16 个汉字。
- `invite`：邀请正文，不超过 60 个汉字（38ch 限宽，两行最合适）。

### `countdown`

- `label`：倒计时上方小字，不超过 8 个汉字。
- `target`：目标时间，写带时区的 ISO 8601，如 `2026-10-18T18:30:00+08:00`。渲染层每秒刷新，到点或时间已过会换成 `done` 文案。
- `done`：到点后的文案，不超过 20 个汉字。
- `units`：四个单位后缀 `days` / `hours` / `minutes` / `seconds`，各不超过 2 个字符。

### `when`

三栏时间地点，`items` 固定 3 条。第 3 栏超过 10 个汉字会折行。

- `title` / `note`：区块标题与一行补充（`note` 不超过 40 个汉字）。
- 每条 `key` 不超过 3 个汉字，`value` 不超过 12 个汉字。

### `program`

当天的流程，`items` 建议 4 条（再多页面会很长）。

- 每条 `time` 用等宽字写时刻，不超过 6 个字符（如 `18:30`）。
- `text` 不超过 12 个汉字；`sub` 可选，不超过 20 个汉字。

### `rsvp`

- `title` / `note`：回执标题与说明。
- `submitLabel`：按钮文字，不超过 5 个汉字。
- `deadline`：提交按钮右侧的等宽小字，不超过 14 个字符。
- `fields`：2-4 项。每项字段：

| 字段 | 说明 | 约束 |
| --- | --- | --- |
| `key` | 生成 `id` 与 `name`，只写英文小写字母，不要重名 | 必填 |
| `label` | 字段名，显示在输入框上方 | 不超过 8 个汉字 |
| `type` | `text` / `choice` / `textarea` | 见下 |
| `placeholder` | `text` 与 `textarea` 的占位文字 | 不超过 20 个汉字 |
| `options` | `choice` 的选项，2-4 项（4 项正好填满一行） | `choice` 必填 |
| `required` | 为 `true` 时提交会校验，为空则标红并把焦点移过去 | 可选 |
| `error` | 校验失败时显示的文案 | 不超过 30 个汉字 |

`choice` 用一排方格单选，第一项默认选中。`textarea` 可以竖向拉高。提交成功后整块换成「回执已收到」，只在前端切换，不发请求。

### `footer`

- `note`：左侧一行，不超过 20 个汉字。
- `contact`：右侧一行，不超过 30 个字符。

## 设计约束

- 识别特征是：深梅黑底、居中窄栏、超大衬线活动名、四格倒计时、三栏时间地点、左键右值的流程表、下划线输入框、实心玫瑰按钮。保持这些比例，不要改成卡片流。
- 全页直角，没有任何圆角（`choice` 也是方格，不是胶囊）。不要引入圆角、阴影、毛玻璃或渐变按钮。
- 强调色只有玫瑰一支，用于倒计时数字、流程时间、选中态、焦点环与主按钮。错误色是独立语义色，不要挪作他用。
- 时间、日期、数量一律等宽字体；正文用系统无衬线；只有活动名、区块标题与时间地点的值用衬线。
- 破折号只用普通连字符 `-`，不要用长破折号或短破折号。

## 动效

只有按钮、输入框与选项的 160ms 颜色过渡，以及每秒一次的倒计时刷新。不要添加滚动动画、入场动画或视差。

## 资源

本模板不需要图片和外部字体，保持离线自包含。`script` 里的 `setInterval` 会在 `beforeunload` 时清除。
