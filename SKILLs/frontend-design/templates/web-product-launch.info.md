# web-product-launch

瑞士网格风格的技术产品发布页。单文件、离线自包含，双击即可打开，不需要构建、不需要联网。

## 形态

- 结构、样式、交互已经做死：`<style>` 与 body 里的骨架不要动。
- 所有文案、数字、配色集中在文件里唯一的 `TEMPLATE` 对象中，位于 `<script>` 顶部的「可编辑区」。
- 交付方式：复制本文件 → 只改 `TEMPLATE` → 其余保持原样。改完不要重写结构，也不要动渲染层。

## 适合

SaaS、开发工具、数据平台、硬件产品的发布页与官网首页。

不适合：电商商品页、活动邀请、个人主页——那些方向请另选模板或自建。

## 字段说明与约束

### `meta`

| 字段 | 说明 | 约束 |
| --- | --- | --- |
| `lang` | 文档语言 | `zh-CN` / `en` |
| `title` | 浏览器标签标题 | 不超过 40 字符 |
| `description` | 页面描述 | 不超过 80 字符 |

### `theme`

配色角色，留空即沿用 CSS 默认值。默认是纸底 + 单一信号色：

| 字段 | 角色 | 默认 |
| --- | --- | --- |
| `paper` | 页面底色 | `#f4f3ef` |
| `paper2` | 次级底（右栏） | `#eceae4` |
| `ink` | 主文字 / 实心按钮 | `#14161a` |
| `muted` | 次级文字 | `#6b6f76` |
| `rule` | 分隔线 | `#d6d4cd` |
| `ruleStrong` | 强调分隔线与描边 | `#14161a` |
| `signal` | 唯一强调色 | `#a8483c` |

改色只改这一组，不要把页面改成深色霓虹或渐变风。

### `brand`

- `mark`：品牌词，1-4 个汉字或 1-2 个短英文词（字号 17px、字距 0.24em，太长会挤）。
- `nav`：3 项最合适，每项 `label` 不超过 6 个汉字；`href` 用 `#` 或区块 id。
- `cta`：顶栏按钮，`label` 不超过 4 个汉字。

### `hero`

- `eyebrow`：小标签，不超过 10 个汉字。
- `title`：主标题，不超过 22 个汉字（54px 字号，超过会顶到第 4 行）。
- `lede`：一句话说明，不超过 60 个汉字。
- `actions`：2 项最常见。`variant` 取 `solid`（实心，主行动）或 `line`（描边，次行动）。
- `figures`：固定 4 格。`value` 只放数字或极短的量（44px 等宽数字，带单位会串行），`unit` 放下方小字说明。

### `compare`

左右两栏对照，适合「接入前 / 接入后」「旧方案 / 新方案」。

- 每栏 `items` 建议 3-4 条，单条不超过 22 个汉字（超过会折行）。
- 序号由渲染层自动生成，不要在文案里写编号。

### `feature`

- `left`：左栏是文字主张 + 一个关键数字。`statValue` 只放数字（大字号），`statNote` 放它下面的一行解释。
- `right`：右栏是说明 + 条形图。`bars` 每项 `label` 不超过 5 字符；`value` 独立成列，控制在 8 字符以内；`width` 是 0-100 的条宽百分比，按同一量纲取相对值（最大值取 88 左右，给右侧留出余量）。最后一条自动用强调色。

### `quote`

- `text`：一句证言，不超过 40 个汉字（衬线 30px，26ch 宽，超过会变 3 行以上）。
- `cite`：姓名 - 职位，一行以内。

### `closing`

收尾行动区，字段同 `hero` 的 `title` / `lede` / `actions`。`title` 不超过 16 个汉字。

### `footer`

- `brand`：页脚品牌词。
- `links`：用 ` / ` 分隔的一行链接文案。

## 设计约束

- 识别特征是：纸底、单一信号色、顶部通栏细线、4 格等分数字行、二分对照表、左 2/3 右 1/3 分栏。保持这些比例，不要改成卡片流。
- 不要引入圆角、阴影、渐变、毛玻璃、emoji 图标。
- 不要改字号刻度、1180px 最大宽度和 32px 外边距节奏。
- 文案语气保持克制、具体、可验证；不要写「赋能」「引领」这类空话。

## 动效

只有链接与按钮的 160ms 颜色过渡，以及 `prefers-reduced-motion` 降级。不要添加滚动动画。

## 资源

本模板不需要图片和外部字体，保持离线自包含。需要图形时用 CSS 画（例如 `.bars` 那种条），不要引入图标库或图片文件。
