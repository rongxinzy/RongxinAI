# web-survey

专注型表单文档：吸顶进度条、编号题目、单选 / 多选 / 量表 / 文本、提交后结果页。单文件、离线自包含，双击即可打开，不需要构建、不需要联网。

## 形态

- 结构、样式、交互已经做死：`<style>` 与 body 里的骨架不要动。
- 所有题目、文案与配色集中在文件里唯一的 `TEMPLATE` 对象中，位于 `<script>` 顶部的「可编辑区」。
- 交付方式：复制本文件 → 只改 `TEMPLATE` → 其余保持原样。改完不要重写结构，也不要动渲染层。

## 适合

客户满意度、用户调研、报名登记、活动反馈、内部问卷。

不适合：多步向导式申请表、带文件上传的表单、需要提交到后端的表单——这类请自建。

## 字段说明与约束

### `meta`

| 字段 | 说明 | 约束 |
| --- | --- | --- |
| `lang` | 文档语言 | `zh-CN` / `en` |
| `title` | 浏览器标签标题 | 不超过 40 字符 |
| `description` | 页面描述 | 不超过 80 字符 |

### `theme`

配色角色，留空即沿用 CSS 默认值。默认是白底 + 单一靛蓝强调：

| 字段 | 角色 | 默认 |
| --- | --- | --- |
| `ground` | 页面底色 | `#ffffff` |
| `ink` | 主文字 / 提交按钮 | `#16171a` |
| `muted` | 次级文字 | `#74777d` |
| `rule` | 分隔线与选项描边 | `#e4e4e6` |
| `accent` | 唯一强调色（进度条、选中态、焦点） | `#2f43b5` |

错误提示色 `--danger` 与文本域底 `--field` 写在 `:root` 里，不在 `theme` 中。改色只改 `theme` 这一组，不要改成深色底。

### `survey`

- `title`：问卷标题，不超过 20 个汉字（32px，超过会到第 3 行）。
- `intro`：卷首说明，不超过 100 个汉字（50ch 限宽）。写清楚用途、耗时与后续动作，不要写「感谢您的参与」这类空话。
- `estimate`：等宽小字，一行以内，如 `4 题 · 约 3 分钟`。题数要与实际题目数一致。
- `questions`：3-6 题最合适（每题上下 34px 间距，题量再大页面会很长）。每题字段：

| 字段 | 说明 | 约束 |
| --- | --- | --- |
| `key` | 用于生成 `name`，只写英文小写字母，不要重名 | 必填 |
| `type` | `radio` / `checkbox` / `range` / `textarea`，其它值按 `textarea` 渲染 | 必填 |
| `title` | 题干，18px | 不超过 30 个汉字 |
| `hint` | 题干下的说明，13px | 不超过 40 个汉字，可省略 |
| `required` | 提交时校验，未答会被标红并提示 | 布尔，可省略 |
| `options` | 仅 `radio` / `checkbox` 使用，建议 3-5 项 | 见下 |
| `min` / `max` | 仅 `range` 使用，默认 0 / 10 | 整数 |
| `minLabel` / `maxLabel` | 仅 `range` 使用，滑块下方两端的说明 | 不超过 8 个汉字 |
| `placeholder` | 仅 `textarea` 使用 | 不超过 40 个汉字 |

- `options` 每项：`label` 是显示文字，不超过 16 个汉字；`value` 与 `label` 相同可省略；`note` 是标签下的灰色小注，不超过 24 个汉字，可省略。
- 量表题的默认值停在中间位置，用户不动它就不算已作答——这是刻意的，不要改成默认计分。

### `submit`

| 字段 | 说明 | 约束 |
| --- | --- | --- |
| `label` | 提交按钮 | 不超过 6 个汉字 |
| `resetLabel` | 清空按钮（带下划线的弱按钮） | 不超过 6 个汉字 |
| `requiredMessage` | 单选/文本/量表未答时的提示 | 不超过 20 个汉字 |
| `checkboxMessage` | 多选一题未选时的提示 | 不超过 20 个汉字 |

### `done`

| 字段 | 说明 | 约束 |
| --- | --- | --- |
| `title` | 结果页标题 | 不超过 16 个汉字 |
| `text` | 结果页说明 | 不超过 60 个汉字 |
| `restartLabel` | 再填一份按钮 | 不超过 6 个汉字 |
| `emptyAnswer` | 未作答项的占位文字，会以斜体灰字显示 | 不超过 8 个汉字 |

### `bar`

- `title`：吸顶栏左侧文字（通常是问卷名的短版），不超过 20 个汉字。
- `progressTemplate`：吸顶栏右侧模板，必须保留 `{done}` 与 `{total}` 两个占位符，其余文字随意。

## 设计约束

- 识别特征是：吸顶细进度条、640px 窄版心、两位数题号、方框选项（单选圆形 / 多选方角）、无圆角文本域、实心深色提交按钮。保持这些比例，不要改成卡片式问卷。
- 单选与多选的原生控件是隐藏的，视觉是自绘的方框标记，选中态为强调色加描边。键盘焦点仍可 `Tab` 到达并有可见描边，改样式时不要破坏这一点。
- 不要引入圆角（除单选圆圈与多选 2px 方角）、阴影、渐变、emoji 图标。
- 不要改 640px 版心、52px 顶部留白和 34px 题目间距。
- 表单是纯前端演示：提交只显示结果页，不发送任何请求，也不记录填写内容。不要接后端或第三方表单服务。

## 动效

只有进度条 240ms 的宽度过渡、选项 140-160ms 的描边与选中过渡，以及 `prefers-reduced-motion` 下关闭过渡的兜底。不要添加题目入场动画或滚动动效。

## 资源

本模板不需要图片和外部字体，保持离线自包含。需要视觉元素时用 CSS 画，不要引入图标库或图片文件。
