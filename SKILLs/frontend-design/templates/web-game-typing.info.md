# web-game-typing

单文件打字练习：逐字符对错反馈、三档时长、实时速度与准确率、结束后给出本轮成绩。打开就能用，不需要构建、不需要联网。

## 形态

- 结构、样式、统计逻辑已经做死：`<style>`、body 骨架与渲染层不要动。
- 所有文案、时长与练习段落集中在文件里唯一的 `TEMPLATE` 对象中，位于 `<script>` 顶部的「可编辑区」。
- 交付方式：复制本文件 → 只改 `TEMPLATE` → 其余保持原样。

## 适合

英文或拼音的盲打练习、录入速度自测、课堂或面试里的打字环节。

不适合：中文输入法测速（本模板按逐字符比对，中文需要走输入法上屏，对错判断不适用）、需要成绩上报的场景（成绩只留在页面里）。

## 字段说明与约束

### `meta`

| 字段 | 说明 | 约束 |
| --- | --- | --- |
| `lang` | 文档语言 | `zh-CN` / `en` |
| `title` | 浏览器标签标题 | 不超过 40 字符 |
| `description` | 页面描述 | 不超过 80 字符 |

### `theme`

配色角色，留空即沿用 CSS 默认值，并跟随系统深浅色自动切换：

| 字段 | 角色 | 浅色默认 |
| --- | --- | --- |
| `paper` | 页面底色 | `#f3f5f4` |
| `panel` | 正文与成绩卡底色 | `#ffffff` |
| `ink` | 已打对的字符、主文字 | `#12171a` |
| `muted` | 还没打到的字符、次级文字 | `#5f6a69` |
| `faint` | 三级文字（计数器） | `#717c7b` |
| `rule` | 细分隔线 | `#dfe4e2` |
| `ruleStrong` | 顶栏粗线、档位描边 | `#c3cbc9` |
| `accent` | 唯一强调色（当前字符下划线、进度条、选中态、主按钮） | `#0f6f66` |
| `onAccent` | 强调底上的文字 | `#f2f8f7` |

错误色 `--bad` 与错误底 `--bad-soft` 写在 `:root` 里，不在 `theme` 中。**只在 `theme` 里写任意一项，页面就会锁定浅色底**，系统深色不再生效；要用深色底就把整组九个值一起写全。

还没打到的字符用 `muted` 而不是 `faint`：它是用户要照着读的正文，对比度必须过 WCAG AA。改色后检查 `muted` 对 `panel` 的对比度。

### `copy`

| 字段 | 说明 | 约束 |
| --- | --- | --- |
| `title` | 页面标题 | 不超过 8 个汉字 |
| `sub` | 标题下一行说明 | 不超过 40 个汉字 |
| `speedLabel` / `speedUnit` | 速度读数的小字与单位 | 单位不超过 4 字符 |
| `accuracyLabel` / `accuracyUnit` | 准确率 | 单位不超过 2 字符 |
| `timeLabel` / `timeUnit` | 剩余时间 | 单位不超过 2 字符 |
| `hint` | 面板底部左侧提示，同时用作输入框的 `aria-label` | 不超过 40 个汉字 |
| `counterLabel` / `counterUnit` | 面板底部右侧计数器 | 不超过 8 个字符 |
| `restartLabel` / `nextLabel` | 两个按钮 | 各不超过 5 个汉字 |
| `resultTitle` | 成绩卡标题 | 不超过 8 个汉字 |
| `resultEmpty` | 还没成绩时的空状态 | 不超过 60 个汉字 |
| `resultKeys` | 成绩四项的名称：`speed` / `accuracy` / `correct` / `wrong` | 各不超过 5 个汉字 |
| `resultNote` | 成绩卡底部说明 | 不超过 60 个汉字 |
| `notes` | 页面底部说明，字符串数组，2-3 条 | 每条不超过 40 个汉字 |

### `rules`

| 字段 | 说明 | 约束 |
| --- | --- | --- |
| `durations` | 时长档位，每项 `label`（不超过 6 字符）与 `seconds` | 3 档最合适 |
| `defaultDuration` | 默认档位下标 | 默认 1 |
| `charsPerWord` | 折算速度时多少个字符算一个词 | 默认 5，英文惯例 |

### `passages`

练习段落，字符串数组，3 段最合适。每段 110-170 个字符（再长正文会到第四行）。用英文最稳妥，因为对错判定是逐字符比对。

- 段落里不要出现换行符，渲染层按 `pre-wrap` 处理，空行会撑高面板。
- 不要放引号嵌套或生僻符号，用户要照着打。

## 操作

- 点正文区域聚焦隐藏输入框，然后直接开始输入；退格可以改错字。
- 第一下按键开始计时，打完一段或时间到都会结算。
- 一轮结束后按 `回车` 直接重开，`换一段` 切到下一段。

## 设计约束

- 识别特征是：冷纸底、深青强调、四项读数条、白色正文面板、面板底部一条 2px 进度线、成绩卡。
- 三种字符状态各有明确颜色：未打到 `muted`、打对 `ink`、打错 `bad`；当前字符只有一条 2px 下划线，不要用整块高亮。
- 全页直角，没有圆角。字距、行高、面板内边距不要压。
- 正文一律等宽字体；统计数字等宽 + `tabular-nums`。
- 破折号只用普通连字符 `-`。

## 动效

只有进度条的 120ms 宽度过渡与按钮、档位的 150ms 颜色过渡。计时器在 `beforeunload` 时清除。

## 资源

不需要图片、图标库或外部字体。输入框是覆盖在正文上的透明 `input`，不要换成手写键盘监听，否则退格与输入法都会出问题。
