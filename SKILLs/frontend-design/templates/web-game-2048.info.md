# web-game-2048

单文件 2048：四乘四棋盘、滑动合并、分数与最高分、撤销一步、分值梯度条。打开就能玩，不需要构建、不需要联网。

## 形态

- 结构、样式、玩法已经做死：`<style>`、body 骨架与渲染层不要动。
- 所有文案、配色、分值梯度与规则集中在文件里唯一的 `TEMPLATE` 对象中，位于 `<script>` 顶部的「可编辑区」。
- 交付方式：复制本文件 → 只改 `TEMPLATE` → 其余保持原样。

## 适合

想在一个页面里直接玩的小游戏、演示页里的互动彩蛋、离线小工具。

不适合：需要排行榜或联机对战的游戏（最高分只存在本机 `localStorage`）。

## 字段说明与约束

### `meta`

| 字段 | 说明 | 约束 |
| --- | --- | --- |
| `lang` | 文档语言 | `zh-CN` / `en` |
| `title` | 浏览器标签标题 | 不超过 40 字符 |
| `description` | 页面描述 | 不超过 80 字符 |

### `theme`

| 字段 | 角色 | 默认 |
| --- | --- | --- |
| `bg` | 页面底色 | `#0f1216` |
| `surface` | 达成提示的底色 | `#171b21` |
| `board` | 棋盘底 | `#151920` |
| `cell` | 空格子 | `#1b2029` |
| `line` | 细分隔线 | `#252b35` |
| `lineStrong` | 顶栏粗线、次级按钮描边 | `#333b47` |
| `ink` | 主文字 | `#e9edf3` |
| `muted` | 次级文字 | `#8e98a6` |
| `faint` | 三级文字 | `#657080` |
| `accent` | 唯一强调色（最高分、主按钮、焦点环） | `#5b86f0` |
| `onAccent` | 强调底上的文字 | `#0b0f16` |

棋盘尺寸是流式的（`--unit` 用 `clamp(58px, 17.5vw, 96px)`），不用改代码就能在窄屏收缩。页面锁定深色。

### `copy`

| 字段 | 说明 | 约束 |
| --- | --- | --- |
| `title` | 页面标题 | 不超过 8 个汉字 |
| `subtitle` | 标题下方等宽小字 | 不超过 30 个字符 |
| `scoreLabel` / `bestLabel` | 两个读数的小字 | 各不超过 6 个汉字 |
| `undoLabel` / `restartLabel` | 两个按钮的文字 | 各不超过 5 个汉字，必须一行放得下 |
| `hint` | 操作条左侧说明 | 不超过 40 个汉字 |
| `legendLabel` | 分值梯度条的小字 | 不超过 6 个汉字 |
| `overTitle` / `overText` | 无路可走时的遮罩，`overText` 里的 `{score}` 会替换成本局分数 | 标题不超过 14 个汉字 |
| `winNote` | 凑出 2048 后出现在棋盘下方的提示 | 不超过 40 个汉字 |
| `rules` | 底部规则，字符串数组，2-3 条最合适 | 每条不超过 40 个汉字 |

### `rules`

| 字段 | 说明 | 约束 |
| --- | --- | --- |
| `storageKey` | 最高分的 `localStorage` 键名 | 换名字即清空记录 |
| `startTiles` | 开局方块数 | 默认 2 |
| `winValue` | 目标分值，达到后显示 `copy.winNote` | 默认 2048 |

### `tiles`

分值梯度，键是分值字符串，值是该格的 `bg` 与 `fg`。渲染层按分值查表，查不到就用 `beyond`。

- 键必须从 `'2'` 起覆盖到 `winValue`，中间不要跳号（梯度条与方块都按这张表上色）。
- `beyond` 是超过 `winValue` 之后的分值配色，必填。
- 建议保持同一条色相、只推明度，这样像一张热力渐变而不是一堆随机色。默认是板岩蓝到冰蓝，低分深、高分浅，到 `128` 之后文字换成深色。
- 每一档的 `bg` 与 `fg` 对比度要过 WCAG AA（4.5:1），改色后逐档检查。

## 操作

- 方向键或 `W` `A` `S` `D` 移动，触屏可以直接在棋盘上滑动。
- `撤销一步` 只回退一步，回退后按钮变灰。
- 一轮无路可走时会弹出遮罩，按 `新游戏` 重开。

## 设计约束

- 识别特征是：深板岩底、圆角方块、顶部两个读数、操作条右对齐两个按钮、棋盘下方一条分值梯度。
- 圆角只用在方块上，按钮与面板都是直角，不要给按钮加圆角。
- 强调色只有一支钴蓝，用在最高分、主按钮、焦点环与梯度条的高分端；棋盘不用色块分割。
- 数字一律等宽字体与 `tabular-nums`，位数变化时不要抖动。
- 破折号只用普通连字符 `-`。

## 动效

只有方块的 120ms 位移、新方块 160ms 的缩放入场、合并时 160ms 的放大回弹、加分数字 760ms 的上浮淡出。位移动画时长写死在 `--settle` 与脚本里的 `SETTLE` 常量，改一个要同时改另一个。窗口尺寸变化时会临时关掉位移过渡。
