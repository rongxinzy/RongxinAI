# web-game-snake

单文件贪吃蛇：canvas 棋盘、三档速度、暂停与重来、本机最近几局记录。打开就能玩，不需要构建、不需要联网。

## 形态

- 结构、样式、玩法已经做死：`<style>`、body 骨架与渲染层不要动。
- 所有文案、配色与规则集中在文件里唯一的 `TEMPLATE` 对象中，位于 `<script>` 顶部的「可编辑区」。
- 交付方式：复制本文件 → 只改 `TEMPLATE` → 其余保持原样。

## 适合

想在一个页面里直接玩的小游戏、演示页里的互动彩蛋、离线小工具。

不适合：需要排行榜或联机对战的游戏（本模板只把最近几局存在本机 `localStorage`）。

## 字段说明与约束

### `meta`

| 字段 | 说明 | 约束 |
| --- | --- | --- |
| `lang` | 文档语言 | `zh-CN` / `en` |
| `title` | 浏览器标签标题 | 不超过 40 字符 |
| `description` | 页面描述 | 不超过 80 字符 |

### `theme`

| 字段 | 角色 | 默认 |
| --- | --- | --- |
| `bg` | 页面底色 | `#0e1113` |
| `surface` | 键帽底 | `#161a1c` |
| `board` | 棋盘底 | `#111517` |
| `grid` | 棋盘格线 | `#1b2124` |
| `line` | 细分隔线 | `#232a2d` |
| `lineStrong` | 档位与方向键描边 | `#333d41` |
| `ink` | 主文字 | `#e6ecec` |
| `muted` | 次级文字 | `#8b9698` |
| `faint` | 三级文字 | `#616d70` |
| `accent` | 唯一强调色（蛇身中段、选中态、主按钮） | `#5fd0a8` |
| `accentHi` | 蛇头 | `#8df0c6` |
| `accentDim` | 蛇尾 | `#2c6a56` |
| `onAccent` | 强调底上的文字 | `#0a1512` |
| `food` | 食物（独立语义色，必须与蛇身区分） | `#e8875f` |

蛇身颜色由 `accentDim` 到 `accent` 逐节插值，蛇头单独用 `accentHi`，所以这三个值要能拉出可见的深浅差。`food` 是玩法语义色（食物必须一眼可辨），不要改成和蛇身同色。页面锁定深色。

### `copy`

| 字段 | 说明 | 约束 |
| --- | --- | --- |
| `boardLabel` | 棋盘的 `aria-label` | 不超过 12 个汉字 |
| `title` | 页面标题 | 不超过 8 个汉字 |
| `subtitle` | 标题下方等宽小字 | 不超过 20 个字符 |
| `scoreLabel` / `bestLabel` | 两个读数的小字 | 各不超过 6 个汉字 |
| `speedLabel` | 档位组的 `aria-label` | 不超过 4 个汉字 |
| `startLabel` / `pauseLabel` / `resumeLabel` / `restartLabel` | 主按钮在四种状态下的文字 | 各不超过 4 个汉字 |
| `overlayPausedTitle` / `overlayPausedText` | 暂停遮罩 | 标题不超过 8 个汉字，说明不超过 30 个汉字 |
| `overlayOverTitle` / `overlayOverText` | 结束遮罩，`overText` 里的 `{score}` 会替换成本局得分 | 同上 |
| `padLabels` | 四个方向键的 `aria-label`：`up` / `left` / `down` / `right` | 各不超过 4 个汉字 |
| `runsLabel` | 战绩条的小字 | 不超过 6 个汉字 |
| `runsEmpty` | 没有记录时的提示 | 不超过 20 个汉字 |
| `keysHint` | 右侧说明。用 `[[空格]]` 这种双中括号包住按键名，渲染层会变成键帽 | 不超过 80 个汉字 |

### `rules`

| 字段 | 说明 | 约束 |
| --- | --- | --- |
| `cols` / `rows` | 棋盘格数 | 默认 24 × 15，改大格子会变小 |
| `cell` | 每格像素 | 默认 26。`cols × cell` 决定棋盘宽度，超过 720 会挤掉右侧面板 |
| `startLength` | 开局蛇长 | 默认 6 |
| `history` | 战绩条最多保留几局 | 默认 5 |
| `storageKey` | `localStorage` 键名 | 换名字即清空记录 |
| `speeds` | 三档速度，每项 `label`（不超过 3 个汉字）与 `stepMs`（每步毫秒，越小越快） | 默认 155 / 108 / 70 |
| `defaultSpeed` | 默认档位下标 | 0 慢 / 1 标准 / 2 快 |

## 操作

- 方向键或 `W` `A` `S` `D` 转向，`空格` 开始与暂停，`回车` 重开。
- 右侧方向键是给触屏用的，点方向键也会开局。
- 切到别的标签页会自动暂停。

## 设计约束

- 识别特征是：近黑橄榄底、等宽字、方形分格棋盘、蛇头带眼、菱形食物、右侧三档速度 + 方向键 + 说明。
- 全页直角，没有圆角。棋盘格只有 1px 格线，不要加发光、外阴影或霓虹描边。
- 强调色只有薄荷绿一支；食物色是玩法语义色，不要拿去做按钮或标题。
- 破折号只用普通连字符 `-`。

## 动效

只有蛇的逐格移动、食物的呼吸缩放、遮罩淡入和按钮的 150ms 颜色过渡。移动端会跟着 `prefers-reduced-motion` 关掉过渡。
