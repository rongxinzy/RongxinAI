# web-ops-console

异常优先的运营监控看板：左侧导航栏、四格指标卡、待处理队列、流转分布与当班名单。单文件、离线自包含，双击即可打开，不需要构建、不需要联网。

## 形态

- 结构、样式与栅格已经做死：`<style>` 与 body 里的骨架不要动。
- 所有文案、数据与配色集中在文件里唯一的 `TEMPLATE` 对象中，位于 `<script>` 顶部的「可编辑区」。
- 交付方式：复制本文件 → 只改 `TEMPLATE` → 其余保持原样。改完不要重写结构，也不要动渲染层。

## 适合

运营监控、订单履约、客服工单、仓库与运力调度、值班面板等异常优先的后台看板。

不适合：面向公众的落地页、个人主页、活动邀请——那些方向请另选模板或自建。

## 字段说明与约束

### `meta`

| 字段 | 说明 | 约束 |
| --- | --- | --- |
| `lang` | 文档语言 | `zh-CN` / `en` |
| `title` | 浏览器标签标题 | 不超过 40 字符 |
| `description` | 页面描述 | 不超过 80 字符 |

### `theme`

配色角色，留空即沿用 CSS 默认值。默认是浅灰底 + 白色面板 + 语义状态色：

| 字段 | 角色 | 默认 |
| --- | --- | --- |
| `bg` | 页面底色、选中导航底 | `#f1f1ed` |
| `panel` | 面板与侧栏底 | `#ffffff` |
| `line` | 细分隔线与卡片描边 | `#e3e2dc` |
| `lineStrong` | 按钮描边 | `#cbc9c0` |
| `ink` | 主文字 | `#1b1d21` |
| `muted` | 次级文字 | `#6f737b` |
| `accent` | 正常态（选中导航、在岗、正常条） | `#2f6f5e` |
| `warn` | 警告态 | `#9c6f1c` |
| `danger` | 严重态 | `#a8433a` |

状态色是这套模板的语义：`accent` 正常、`warn` 警告、`danger` 严重。不要改成只有一种强调色的看板，也不要改成深色底。

### `copy`

| 字段 | 说明 | 约束 |
| --- | --- | --- |
| `mark` | 左上角产品词 | 2-4 个汉字（15px、字距 0.16em） |
| `nav` | 侧栏导航，固定 5 项最合适 | 每项 `label` 不超过 5 个汉字；恰好一项写 `on: true` 表示当前页 |
| `foot` | 侧栏底部值班信息 | 不超过 20 个汉字 |
| `refreshLabel` | 右上角按钮 | 不超过 4 个汉字 |
| `stampJustNow` | 刚刚刷新时的提示 | 保留「刚刚」 |
| `stampTemplate` | 计时提示模板，必须保留 `{seconds}` | 其余文字随意 |

### `view`

| 字段 | 说明 | 约束 |
| --- | --- | --- |
| `title` | 页面标题，21px | 不超过 12 个汉字 |
| `subtitle` | 标题下方口径说明，12px | 不超过 30 个汉字，写清时间范围与排序口径 |
| `kpis` | 指标卡，固定 4 格 | 见下 |
| `queue` | 待处理队列 | 见下 |
| `dist` | 流转分布 | 见下 |
| `shift` | 当班名单 | 见下 |

- `kpis` 每项：`label` 不超过 8 个汉字；`value` 只放数字与单位（27px 等宽数字，写 `3,148` `96.4%` `12m 38s` 这类具体值，不要凑整）；`delta` 是下方一行解释，不超过 20 个汉字；`alert: true` 让这张卡整块转成严重态，建议固定放在第 4 格。
- `queue.rows` 建议 6 条（按影响面从大到小排）。`no` 不超过 10 字符；`who` 不超过 6 个汉字；`chip` 不超过 8 个汉字；`tone` 取 `critical` / `warn` / `steady` / `plain`（对应严重 / 警告 / 正常 / 中性，省略即中性）；`dur` 不超过 10 字符；`hub` 不超过 8 个汉字。窄屏下 `hub` 与 `dur` 整列隐藏，不要把关键信息只放在这两列。
- `dist.items` 固定 4 条。`label` 不超过 5 个汉字；`value` 只放数字；`width` 是 0-100 的条宽百分比，按同一量纲取相对值（参考实现里 18,662 单用 88、27 单用 4，刻意不用线性比例，避免小值看不见）；`tone` 取 `warn` / `critical`，省略则用正常色。
- `shift.rows` 建议 3 条。每项写 `name` + `role` + 二选一：`now`（在岗，强调色）或 `note`（交接时间，次级色）。

## 交互

- 「数据更新于 … 秒前」是本地计时，每 5 秒递增；点刷新只把计数归零并刷新文案，**不发起任何网络请求**。不要接真实数据源或轮询接口。
- 侧栏链接与刷新按钮是可聚焦控件，键盘可到达；改样式时不要移除焦点态。

## 设计约束

- 识别特征是：176px 左栏 + 主区两栏（队列 1fr / 侧栏 268px）、四格等分指标卡、细线分隔的队列表格、无底槽的 3px 细条、右上角时间戳与刷新按钮。保持这些比例，不要改成图表化的仪表盘。
- 进度类信息用无底槽细条或纯数字表达，不要加圆环图、仪表盘、大面积色块或滚动动画。
- 异常项必须在第一屏可见且明显（卡片的 `is-alert`、状态的 `critical` 色）。不要把异常藏在次级页面或表格底部。
- 圆角固定 6px（`--radius`），不要引入更大的圆角、阴影、渐变、毛玻璃或 emoji 图标。
- 数字一律用 `font-variant-numeric: tabular-nums` 对齐，不要在文案里补空格凑宽度。

## 动效

只有导航、按钮与刷新按钮的 140ms 颜色过渡，以及 `prefers-reduced-motion` 下把过渡压到 1ms 的兜底。不要添加数字滚动、卡片入场或自动刷新闪烁。

## 资源

本模板不需要图片和外部字体，保持离线自包含。需要视觉元素时用 CSS 画（流转条已经是这种实现）。
