# web-store

陶艺工作室 / 器物店的展示与菜单页：左侧 CSS 器物静物、右压角信息卡、招牌三件、点线器物单、到店信息。单文件、离线自包含，双击即可打开，不需要构建、不需要联网。

## 形态

- 结构、样式、交互已经做死：`<style>` 与 body 里的骨架不要动。
- 所有文案与配色集中在文件里唯一的 `TEMPLATE` 对象中，位于 `<script>` 顶部的「可编辑区」。
- 交付方式：复制本文件 → 只改 `TEMPLATE` → 其余保持原样。改完不要重写结构，也不要动渲染层。

## 适合

陶艺、烘焙、咖啡、花店、理发店、面包房、手作器物等小型实体店的展示页与菜单页。

不适合：SaaS 与开发工具官网、个人简历、活动邀请，那些方向请另选模板或自建。

## 字段说明与约束

### `meta`

| 字段 | 说明 | 约束 |
| --- | --- | --- |
| `lang` | 文档语言 | `zh-CN` / `en` |
| `title` | 浏览器标签标题 | 不超过 40 字符 |
| `description` | 页面描述 | 不超过 80 字符 |

### `theme`

配色角色，留空即沿用 CSS 默认值。默认是冷骨白底 + 橄榄绿强调 + 砖红次强调：

| 字段 | 角色 | 默认 |
| --- | --- | --- |
| `paper` | 页面底色、台面 | `#eef0e9` |
| `paper2` | 网格纹理底（首屏大图、招牌图、地图底） | `#e3e7dd` |
| `card` | 信息卡底色 | `#f8f9f5` |
| `ink` | 主文字 / 实心按钮 / 粗分隔线 | `#20241d` |
| `muted` | 次级文字 | `#6b7064` |
| `rule` | 细分隔线 | `#d2d7ca` |
| `accent` | 强调色（卡片顶边、盘与瓶） | `#55682f` |
| `accent2` | 次强调（价格、碗、地图标记） | `#a9482a` |

页面跟随系统深浅色自动切换。注意：一旦在 `theme` 里写了任意一项，页面会锁定为浅色底，避免两套变量互相覆盖。

### `shop`

- `name`：店名，2-6 个汉字（20px 衬线、字距 0.42em，超过 8 字会挤掉右侧导航）。
- `hoursShort`：顶栏右侧等宽小字，一行以内，如 `周二至周日 10:00-19:00`。窄屏下隐藏。
- `nav`：固定 3 项最合适，`label` 不超过 4 个汉字；`target` 写锚点（`#picks` / `#menu` / `#visit`）。

### `hero`

- `badge`：小标签，不超过 16 字符（11px、字距 0.22em、转大写）。全页只此一处小标签，不要再给别的区块加。
- `title`：主标题，不超过 18 个汉字（38px 衬线，卡片宽 460px，超过会到第 3 行）。
- `slogan`：一句话说明，不超过 40 个汉字。
- `primary` / `secondary`：两个按钮，`label` 不超过 5 个汉字；`target` 写锚点 id。

### `picks`

三栏网格，`items` 固定 3 条。第 1 条画碗、第 2 条画盘、第 3 条画瓶，文案要与图形对得上。

- `title`：区块标题。
- `note`：标题右侧等宽小字，不超过 14 字符（如 `每窑约 40 件`）。
- `lede`：区块导语，不超过 50 个汉字（54ch 限宽）。
- 每项 `name` 不超过 10 个汉字；`price` 不超过 10 字符（等宽字，写 `96 元 / 只` 这类带单位的形式）；`note` 不超过 30 个汉字。

### `menu`

两栏分组，`groups` 固定 2 组（多于 2 组会换行且失去栏对齐）。

- `title` / `lede`：区块标题与导语。单价单位写进 `lede`，条目里不再重复。
- 组名 `name`：不超过 4 个汉字（12px、字距 0.2em、转大写，下方是 2px 粗线）。
- `items` 建议每组 5 条；`name` 不超过 10 个汉字；`sub` 是名称下方小字，不超过 14 个汉字；`price` 只写数字（等宽字右对齐，不要带货币符号）。
- 名称与价格之间的点线由渲染层生成，不要在文案里手写 `......`。
- 条目之间没有分隔线，只有点线；不要给每条加下边框。

### `visit`

左右两栏：左侧门店信息，右侧位置示意。

- `title`：区块标题。
- `infoLabel` / `mapLabel`：两栏的小标题，各不超过 6 个汉字。
- `lines`：固定 4 条最合适；`key` 不超过 2 个汉字（列宽 68px，如 地址 / 营业 / 电话 / 提示），`value` 不超过 40 个汉字（超过会折行）。
- 右侧地图是 CSS 画的网格、道路与标记点，没有真实地图能力；不要把地址换成嵌入地图代码。地图标签自动取店名。

### `closing`

- `title`：收尾标题，不超过 14 个汉字。
- `text`：一行说明，不超过 50 个汉字。
- `primary` / `secondary`：两个按钮，`label` 不超过 6 个汉字；`href` 可写 `tel:` 或锚点。全页同一意图只用一个说法：引导到店的按钮统一写「预约到店」。

### `footer`

- `brand`：页脚店名。
- `note`：一行补充，不超过 24 字符。

## 设计约束

- 识别特征是：冷骨白纸底、左大图右压角的骨白信息卡、卡片顶部彩色粗线、点线器物单、双栏门店信息、居中收尾区。保持这些比例，不要改成卡片流。
- 首屏大图、招牌图与地图都是纯 CSS 图形（网格底纹 + 台面横线 + 圆形与弧线器皿剪影），不是图片位。不要在页面里引入图片文件或图标库。
- 不要引入圆角与阴影（器皿剪影的弧线与地图标记光晕除外）、毛玻璃、emoji 图标。
- 不要改 1080px 最大宽度、76px 区块间距和 68px 顶栏高度。
- 价格与时间一律等宽字体；文案用具体名词与动词，不要写「匠心」「治愈」这类空话。
- 破折号只用普通连字符 `-`，不要用长破折号或短破折号。

## 动效

只有导航与按钮的 160ms 颜色过渡，以及顶栏的 `sticky` 定位。不要添加滚动动画、视差或图片放大效果。

## 资源

本模板不需要图片和外部字体，保持离线自包含。深色模式由 `prefers-color-scheme` 自动切换，无需额外资源。
